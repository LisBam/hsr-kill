# AI 模块

## 冰封与酒杀保护

- 【冰封】仍可在使用牌指定唯一目标后选择竖直目标或弃置其一张手牌，并令该牌对非自身目标无效；规则文本与玩家可选项不变。
- AI在 `useCardToTargeted` 的【冰封】确认评分中，若当前牌对非自身目标、其 `effect_id` 为 `slash` 且技能持有者公开 `wine_bonus > 0`，确认发动固定为强负分。此时酒的 `+1` 伤害尚未被【杀】共享结算消耗，确认冰封会使该张酒杀直接无效，因此不能以弃牌、竖直或无效原牌收益抵消该损失。
- 同一保护也作用于主动出牌评分修正：带酒加成的【杀】不再被【冰封】转换为“对横置友方的负收益牌”，保留原始卡牌评分。普通【杀】的既有横置友方转竖直评估不变。

## 一、源码依据与复刻范围

当前基础 AI 以项目内置无名杀 `v1.10.16` 源码快照为行为依据，主要对应：

- `noname/ai/basic.js`：按评分逐步选择牌、目标和按钮，非强制选择在最高分不大于0时停止。
- `noname/get/index.js`：`get.value`、`get.effect`、`get.condition`、`get.attitude` 等通用估值。
- `mode/identity.js`：`rawAttitude`、`realAttitude`、`situation` 与 `player.ai.shown` 身份暴露逻辑。
- `card/standard.js`、`card/extra.js`：卡牌 `ai.basic/order/result/tag/equipValue/expose` 数据和复杂卡牌判断。
- 各武将包技能源码：技能定义内的 `ai.check/order/result/effect/threaten`，即技能效果与配套 AI 同文件维护。

Godot 版本复刻上述分层思想，不执行 JavaScript，也不让 AI 直接调用规则效果。当前范围是标准身份局、项目已登记46种卡牌与55个由正式武将引用的唯一技能。

## 二、运行架构

AI 不持有 `GameState` 的可变引用。每次行动固定执行：

1. `MatchController` 使用卡牌规则、装备和技能实例枚举合法动作。
2. 控制器生成 `state.to_dict(player_id, true)` 权威完整快照。
3. `AICoordinator` 把快照与合法动作交给对应 `BasicAIPolicy`。
4. `NonameAIEvaluator` 组合身份态度、卡牌价值、目标效果、角色状态与内容文件 AI 钩子。
5. 策略只返回可序列化动作字典。
6. 动作恢复为 `PlayerAction`，进入与人类和网络玩家相同的 `submit_action()` 权威校验。

选择请求同样只从规则层生成的合法动作中决策。AI 不能移动牌、修改体力、跳过距离、伪造目标或绕过次数限制。

装备栏与判定区废除不建立AI专用白名单。合法动作枚举会读取公开 `abolished_equipment_slots/judgment_area_abolished`，对应栏位的装备牌和面向废除判定区的延时锦囊在评分前即被 `CardRuleService` 排除；其他未废除装备栏仍可正常生成动作。若状态在异步AI延迟期间变化，提交入口与最终移牌边界会再次校验，旧动作失败后由统一AI恢复出口重建最新合法动作。废除占位不是实体牌，不进入装备数量、区域候选、弃置收益或获得牌估值。

静态内容与运行时决策采用不同生命周期：`BasicAIPolicy`、`NonameAIEvaluator` 和 `IdentityStrategyEvaluator` 各自在自身职责内缓存 `GameDatabase` 返回的卡牌或武将元数据独立副本，同一定义后续评分不再重复深拷贝；`BasicAIPolicy` 只在一次合法动作集合评分期间复用武将技能和主动技能的纯 AI 实例，并在返回动作前清空。`IdentityAIModel.begin_evaluation()` 会在本次普通行动、统一选择、无懈判断或装备材料排序开始时完成一次身份观察同步，并额外遍历最多10名玩家1次建立玩家 ID、存活身份人数、身份首名玩家和存活总数索引；同批最多256组选择组合的后续查询不再重复扫描玩家表，局势值与“反贼是否全部暴露”判断也按需复用。`end_evaluation()` 在返回结果前立即清空全部玩家字典引用，静态缓存仍不保存 `GameState`、玩家快照、合法动作、选择结果、技能结算字段或节点引用，因此下一次决策完全读取最新权威快照。所有 `score_ai_action()`、`score_ai_choice()` 与 `modify_ai_card_action_score()` 都必须保持只读，不能依靠技能实例字段在候选之间累积结果。

## 三、组件职责

| 组件 | 职责 |
|---|---|
| `AICoordinator` | 管理玩家到策略的映射，共享身份观察模型，转发普通行动、选择、无懈、装备材料和公开技能行为，并向界面只读公开忠反临时标记。 |
| `BasicAIPolicy` | 在合法动作中选择最高正收益动作；无正收益时结束出牌阶段；可取消选择在最高确认分不大于0时取消。 |
| `IdentityAIModel` | 计算标准身份局局势、真实态度、隐藏身份暴露度、忠反行为标记与角色综合强度。 |
| `IdentityStrategyEvaluator` | 计算领袖危险、敌方威胁、阵营集火、内奸控场、残局保护与濒死救援。 |
| `NonameAIEvaluator` | 读取卡牌文件 `ai` 配置，计算使用牌、重铸、装备、响应、弃牌、获得牌、目标效用和统一资源变化收益。 |
| `CardDefinition` | 保存本卡牌 AI 数据，并可覆盖复杂卡牌动作、选择、自定义装备评分和逐目标身份观察牌效。 |
| `SkillDefinition` | 提供主动动作、选择请求、持有者用牌联动、目标来牌结局修正与通用 `sell_blood_value` 卖血估值等 AI 钩子；具体专属实现必须写在对应技能 GD 文件。 |

AI 的直接资源变化统一通过 `NonameAIEvaluator.score_resource_change()` 计算：基础尺度固定为1张牌等于1点资源收益、1点体力等于2点资源收益，即“1点体力=2张牌”。该函数再乘观察者对目标的态度比例，因此自身直接获得1张牌和回复1点体力通常分别得到2.0分和4.0分。卡牌保留价值、重铸换牌和未知牌质量比较仍使用独立的4.5分原始牌质尺度，不能与“牌数净变化”混算。

每个技能实例都拥有非负浮点数 `sell_blood_value`，元数据缺省为 `0.0`；1.0点固定等价于1张牌的上述基础资源价值。通用来牌评分预计该技能持有者受到伤害时，攻击者与目标关系为敌对则从伤害收益减去该值，关系为友方则加上该值；中立关系不修正。多个有卖血价值的技能逐项累计，不改变伤害量、触发条件或实际摸牌。当前【百折】为 `1.0`，其余正式技能为 `0.0`。

【铁索连环】的使用动作与同一实体牌的重铸动作必须同时估值：恰好只有 **2名存活在场角色** 的1v1局面固定重铸并摸1张，不评估横置目标；三人及以上局面若使用没有任何正收益目标，或使用总分未比重铸摸1张的得分高出 **0.15** 分，AI 选择重铸。该人数判断和阈值仅决定 AI 行为，不改变【铁索连环】的横置/解除连环效果、重铸规则或实际摸牌数。

## 四、身份判断与游戏思维

### 4.1 局势强度

`IdentityAIModel.get_situation()` 复刻无名杀标准身份局公式：

- 单名角色基础强度 = 手牌数 + 装备数 × 1.5 + 体力 × 2，体力最高按6计。
- 领袖强度计入 `基础强度 × 1.2 + 5`。
- 忠臣强度计入 `基础强度 × 0.8 + 3`。
- 反贼强度计入 `基础强度 + 4`，并从领忠净强度中扣除。
- 最终结果归一化到约 `-10` 至 `10`；正数代表领忠优势，负数代表反贼优势。
- 领袖基础强度低于12且反贼总强度高于30时结果额外 `-1`；低于6且反贼总强度高于15时再 `-1`；低于4时再 `-1`。

### 4.2 真实态度

`get_real_attitude()` 使用领袖、忠臣、反贼、内奸四身份关系表，并对二人、三人残局、反贼或忠臣清空、领忠局势明显占优等情况动态调整。内奸不会固定把所有其他角色视为敌人，而是根据局势维持双方平衡，进入单挑后再转为明确敌对。

### 4.3 隐藏身份与暴露度

权威 AI 快照包含规则执行所需的真实身份，但决策层不能直接把隐藏身份当作已知目标。`IdentityAIModel` 先根据公开行为生成暴露度与忠反标记，战略层只读取公开身份或行为标记：

- 身份公开或领袖：暴露度固定为 `1.0`。
- 隐藏身份初始暴露度：`0.0`。
- 目标证据按其暴露度绝对值加权：小于 `0.2` 为 `0`，`[0.2, 0.4)` 为 `0.5`，`[0.4, 0.6)` 为 `0.8`，达到 `0.6` 为 `1.0`；目标真实身份为内奸时固定为 `0`。因此行动者不能借未暴露目标的隐藏真实身份获得忠反标签。
- 普通用牌先由 `CardDefinition.get_identity_observation_ai_profile()` 生成逐目标动态结果：通用回复标签在目标满体力时返回0，【铁索连环】按未横置 `-0.5`、已横置 `+0.5` 区分施加与解除连环；身份模型不维护卡牌 ID 分支。
- 明确单目标行为的基础步长为 `0.2`；多目标行为基础步长为 `0.1`。
- 只有加权行为符合行动者自身收益时才增加基础暴露度；正收益小于 `1.0` 时只增加一半步长。唯一目标为行动者本人时不增加目标行为暴露。
- 忠臣作用于暴露度严格为 `0.0` 的其他未知角色且可感知牌效为0时，追加固定 `0.1` 弱收益，再按上述单目标或多目标规则换算暴露；该补偿不读取目标隐藏身份。
- 只有本地观察者本人为内奸且行为违背其当前真实收益时，基础暴露度才按 `0.2/0.1` 减少；其他角色的反向行为不伪造负暴露。
- 卡牌 `ai.expose`：额外累加对应数值；【无懈可击】当前为 `+0.2`。
- 从本地观察者视角记录其他角色行为后，更新后的总暴露度整体乘 `2.0`；本地角色自身不乘。最终暴露度范围为 `-0.5` 至 `0.95`。
- 【无懈可击】只有在原锦囊使用者暴露度非0且响应者不是当前目标本人时才记录；其忠反方向按原锦囊 `target_result` 和响应后的抵消奇偶状态计算。
- 领袖视角的行为方向仍按单目标 `0.2`、多目标 `0.1` 记录到 `-1.0..1.0` 诊断信号，但不再直接按累计正负反复改标。
- 忠臣与反贼只有在行为符合自身收益并形成正暴露后才分别定型为 `loyalist` 或 `rebel`，随后标记进入终结状态；一次误操作或伪装不会贴成相反身份。
- 内奸可按本次行为对领袖阵营的方向暂时标记为 `loyalist` 或 `rebel`；若后续出现与现有标记相反的行为，立即清空并进入终结状态，不再来回翻转。场上没有存活反贼时，内奸的反向行为不形成 `rebel` 标记。
- 本地观察者本人、唯一目标为本人、领袖及身份已公开角色不生成自动猜测；公开身份在态度计算中始终覆盖旧临时标记。
- 隐藏目标存在忠反标记时，态度判断最低使用 `0.5` 可信权重。
- 当其他存活反贼均已有行为暴露时，尚未暴露的隐藏非领袖、非反贼角色获得 `0.3` 的最低判断权重。

身份观察只记录权威确认后的公开使用牌、成功打出的【无懈可击】、实际生效的濒死救援与技能主动选择目标，不读取 UI 临时选择，不修改规则状态。【桃】救援沿用卡牌 `target_result=2.0` 对实际濒死目标上报，本人自救因唯一目标为本人而忽略；当前【天坠】按 `target_result=-1.0` 上报伤害行为，【军势】【行军】【药理】【焕发】按正向结果上报帮助行为，【冥谶】选择其他角色时按伤害行为上报。锁定技【还阳】【摄伏】不把强制结果作为主动身份线索。技能通过 `SkillDefinition.observe_identity_behavior()` 上报通用数据，协调器不维护技能 ID 白名单。即使当前没有注册内置 AI 策略，`AICoordinator` 仍调用共享模型记录公开行为，供本地“自动标记身份”使用。对局 ID 变化时，暴露度、诊断信号、标记和终结状态会一并清空，旧对局观察不能泄漏到新对局。

“自动标记身份”默认开启。`AICoordinator.get_identity_mark(player_id)` 只返回 `loyalist`、`rebel` 或空字符串，`identity_mark_changed` 只在公开行为令该值变化时通知界面；它不返回真实隐藏身份或可变模型。关闭设置只停止界面显示，公开行为观察与终结状态仍在本局持续记录，重新开启后立即恢复现有推断。手动标注与真实身份的显示优先级由界面负责，不能反向影响 AI 态度。

联机对局中，房主在每次公开行为观察之后把**行为本身**广播为 `identity_behavior` 或 `identity_response` 事件：前者只含行为玩家稳定 ID、房主按当时权威快照算好的只读 `ai_profile` 与实际公开目标；后者只含响应者稳定 ID、响应牌与锦囊的定义 ID，以及 `source_id`、`target_id`、`negated` 三个公开键。非房主客户端收到后调用本地 `AICoordinator` 重放同一推断，观察者固定为客户端自己的 `local_human_player_id`，因此本地座位的行为与房主端一致地不参与自动标记。网络只承载公开行为，绝不下发房主算好的标记结果，隐藏手牌、私有候选与完整结算上下文都不进入这两个事件；每个客户端仍各自持有独立推断，关闭本地开关只影响本机显示。

### 4.4 身份局战略

`IdentityStrategyEvaluator` 在通用牌效之外追加身份模式的全局思维：

- 领忠方优先压制已公开或已被标记的反贼；目标威胁按 `0.3` 权重、领袖危险按 `0.45` 权重加入负面牌评分。
- 反贼攻击领袖获得 `3.0 + 领袖危险×0.7` 的集火分；攻击忠臣仅按 `威胁×0.2` 加分，领袖危险达到 `4.0` 时再减 `1.5`，避免错过终结窗口。
- 场上仍有反贼时，领忠攻击内奸降权 `1.0`；反贼清空后攻击内奸加权 `2.5`。
- 内奸在局势大于 `1` 时压制领忠方，在局势小于 `-1` 时压制反贼方：正确控场目标加 `3.0`，帮助优势方或攻击弱势方减 `2.0`。
- 均势时内奸按目标 `condition×0.2` 压制场上强者；多人局中对1点体力领袖施加预期致命负面效果额外减 `12.0`。
- 领袖危险度达到 `4.0` 时，内奸为领袖施加正面效果加 `6.0`，避免领袖提前死亡。

目标威胁由 `condition + 已知伤害牌数×0.6 + 是否有武器×1.0` 构成，再乘 `max(-attitude/5.0, 0.25)`。领袖危险度为 `max(3-领袖体力, 0)×2 + max(2-领袖手牌数, 0) + 敌方 condition 总和×0.15`；反贼全部计入，反贼清空后内奸也计入。

濒死救援基础收益为 `8.0`。自救额外加 `6.0` 且只计算救援牌一半成本；每额外缺少1点回复量减 `1.5`。忠臣救领袖额外加 `8.0`，多人局内奸救领袖加 `7.0`，反贼救领袖减 `20.0`；同阵营反贼或内奸扶助弱势方加 `4.0`，领忠救忠臣加 `3.0`。救援牌按完整保留价值扣分，救援者只有1点体力且目标不是领袖时再减 `3.0`。AI 还按被救角色后续行动能力降低价值：没有手牌减 `2.5`；从下一名存活角色起计算回合距离，第2个座次开始每远1席减 `0.75`，最多减 `3.0`；判定区有【乐不思蜀】减 `2.5`，有【兵粮寸断】减 `1.5`。这些修正只作用于 AI 对正态度目标的救援评分，不改变【桃】的实际回复量或求桃顺序。

### 4.5 目标与牌效

卡牌目标效果使用 `target_result × attitude` 计算：负面牌对敌方形成正收益，正面牌对友方形成正收益。伤害牌还应用无名杀式状态修正：

- 目标1点体力：伤害目标效果 × `2.5`。
- 目标2点体力：伤害目标效果 × `1.8`。
- 目标0张手牌：通常 × `1.5`；要求响应【杀】或【闪】时 × `1.7`。
- 目标1张手牌：× `1.3`。
- 目标2张手牌：× `1.1`。
- 目标3张或以上手牌：× `0.5`。
- 目标已知拥有所需【闪】或【杀】：预期伤害倍率再 × `0.35`。
- 目标没有已知【闪】但装备【八卦阵】：预期伤害倍率再 × `0.65`。
- 1点体力目标已知拥有【桃】或自救【酒】：预期击杀倍率再 × `0.7`。
- 目标装备【仁王盾】且本次实体【杀】为黑色时，该目标收益按 `ARMOR_VOID_TARGET_PENALTY = -0.5` 计（**明确为负**，不再按 `0` 处理）；目标装备【藤甲】且未被无视防具时，普通【杀】、【南蛮入侵】和【万箭齐发】的确定无效目标收益同样按 `-0.5` 计；火焰伤害的 AI 目标收益额外 × `2.0`，对应藤甲实际使火焰伤害 `+1` 的收益提升。`-0.5` 等于半张牌的资源价值，语义是“没有产生任何牌效却仍消耗了这张牌与一次出牌机会”的净损失。
- 火焰或雷电伤害命中横置目标时，会继续估算其他横置角色的连环收益：行动者自身横置时，传导自伤损失额外乘 `1.5`；任一传导受击者为1点体力时再乘 `2.5`，行动者自身为1血时额外减 `12.0` 分。故属性伤害不会只按首个敌方目标估值。
- 面对需要使用【闪】的可取消响应时，若响应者横置、伤害来源为友方、伤害为非普通属性、预计伤害未使自身进入濒死，且全部存活敌人都横置，AI在正常 `6.0` 分生存收益上扣 `8.0` 分，选择不使用【闪】以让属性伤害经自身传导至全部敌人；只要任一敌人未横置、来源不友方、伤害无属性或自身会被该段伤害打至濒死，就保留正常响应逻辑。
- 任一预计以1点伤害击杀的已确认身份目标都会计入死亡后果：击杀反贼加 `3.0` 分（规则摸3张牌），击杀已确认同阵营角色减 `8.0` 分；主公击杀忠臣额外减 `12.0 + 2.0×(主公手牌数+装备数)` 分，对应弃置全部手牌和装备。身份未知时不读取真实身份，不套用上述阵营奖惩。上述分值是**规则侧基础奖惩对应的估值**；行动者技能可以通过 `modify_ai_lethal_damage_consequence()` 在结论之后撤销、替换或追加修正，因此同一次击杀对不同武将可以得到完全相反的评分（当前【征服】即会把误杀忠臣惩罚换成摸四张牌的收益）。
- 回复牌对满体力目标的目标收益为0。

领袖技 AI 仍遵守隐藏身份可见性与领袖技归属过滤：非领袖选择布洛妮娅或姬子时不会应用对应技能钩子。【振旗】由回合开始的贝洛伯格角色根据自己的资源支付费用：弃置分支要求支付后至少保留1张手牌，失去体力分支要求当前体力至少3；弃牌分支优先帮助手牌少于3张的正态度同势力队友摸1张，失去体力分支优先帮助已损失体力的正态度同势力队友回复1点。两项均把最需要对应效果的合法受益者评分除以 `2.0` 后再扣弃牌 `1.0` 或失去体力 `2.0`，只有最终分严格大于0才发动；领袖选择目标时也按同一对应效果需求排序。【领航】确认收益为姬子对连环事件来源角色的态度除以 `2.0`；来源角色选择重铸时使用“未知牌质价值 `4.5` - 所选手牌保留价值”，严格大于0才确认，否则取消。确认【领航】后即使来源角色取消重铸，本回合次数仍已消耗，AI 评分不能返还规则次数。

## 五、卡牌 AI

项目46个卡牌文件全部声明本地 `ai` 字典，不在 `BasicAIPolicy` 中维护卡牌 ID 白名单。常用字段：

| 字段 | 含义 |
|---|---|
| `order` | 出牌顺序；收益接近时优先使用高值动作。 |
| `value` | 手牌保留价值；可为单个数值或按同名牌数量递减的数组。**读取时必须先判型再转换**：GDScript 对 `Array` 直接调用 `float()` 会抛 `Nonexistent 'float' constructor` 运行时报错，该报错会中断整轮 AI 决策（技能不再产出任何动作，表现为 AI 回合静止）。有权重上下文的场景按同名牌张数取档（`NonameAIEvaluator.get_card_value_by_id`）；没有持有数量上下文的场景统一取数组首项（`touxia` / `xifa` / `xingqi` / `linggan`），空数组与首项非数值回退 `1.0`。 |
| `equip_value` | 装备场面价值；换装时扣除同槽旧装备价值。 |
| `player_result` | 对使用者自身的直接收益。 |
| `target_result` | 对目标的基础效果；正值有利，负值有害。 |
| `damage` | 是否属于伤害效果，启用低体力与少手牌倍率。 |
| `fire_damage` / `thunder_damage` / `nature_damage` | 属性伤害与连环估值。 |
| `respond_sha` / `respond_shan` | 目标是否需要响应【杀】或【闪】。 |
| `recover` / `save` / `draw` | 回复、救援与摸牌语义。 |
| `lose_card` / `discard` / `gain` | 失去牌、弃牌与获得牌语义。 |
| `skip_play` / `skip_draw` | 跳过出牌或摸牌阶段。 |
| `multitarget` | 多目标效果。 |
| `beneficial` | 无懈判断中的通常正面效果。 |
| `expose` | 使用该牌额外增加的身份暴露度。 |

特殊卡牌继续在自身文件覆盖钩子：

- 【铁索连环】枚举包括使用者本人在内的全部合法单目标与不重复双目标组合；1v1恰好2名存活在场角色时直接把全部使用动作压到同实体重铸动作之后，三人及以上才根据每名目标当前是否横置反转施加/解除连环的收益方向，并比较整组收益决定使用或重铸。无懈评估仍复用动态逐目标结果：目标已横置时，本次效果为解除连环的正收益 `+0.5`，友方 AI 不会把它误判为负收益而使用【无懈可击】。
- 【借刀杀人】的卡牌动作在使用时生成“持刀者、被【杀】者”完整两目标组合；AI 只提交持刀者攻击范围内的合法第二目标。卡牌进入实际目标时机时仍只保留持刀者，第二目标从已声明上下文直接用于强制【杀】。当队友对持刀者本人使用【借刀杀人】时，持刀者对敌人打出【杀】和拒绝后把武器交给队友都属于团队正收益，因此第一张【无懈可击】视为负收益而不使用；若锦囊已被抵消，反无懈则按同一奇偶规则倾向恢复其生效。
- 【闪电】根据身份与领忠局势决定是否引入随机伤害。
- 【木牛流马】按手牌溢出量和材料保留价值决定存粮，并优先存低价值牌；材料可为当前不能直接使用的任意普通手牌。AI 动作中的材料 UID 只用于装备定义复核，提交活动 `chooseToUse` 时使用木牛装备本体 UID。
- 【丈八蛇矛】枚举两张普通手牌的全部不同组合，按每对材料的聚合花色与颜色生成合法目标（两张黑色牌不会生成指向拥有【琥珀】角色的组合，两张红牌与一黑一红组合不受影响），复用【杀】目标效用并扣除材料价值；其虚拟【杀】继续进入持有者的完整用牌技能评分链。
- 实体【杀】或伤害类群体锦囊若对全部实际目标都会被【仁王盾】或【藤甲】拦截，AI先完成卡牌和武将技能联动评分，并移除仅用于同收益排序的 `order` 分；剩余收益不严格大于0时评分为负无穷而不使用。被拦截目标自身的收益已按 `ARMOR_VOID_TARGET_PENALTY = -0.5` 计为明确负值，因此黑色【杀】不会无意义攻击仁王盾，普通【杀】、【南蛮入侵】和【万箭齐发】不会无意义攻击藤甲；该惩罚幅度小于“一张低价值牌的资源成本 + 技能联动收益”，故【星火】等仍能产生严格正向独立收益的技能会保留合法出牌。青釭剑等无视防具武器在读取目标防具前就已返回空防具，保留正常评分。
- 伤害类群体锦囊逐名目标调用同一伤害估值，因此1血已确认友方会同时触发濒危倍率和死亡后果；属性伤害则在首目标横置时把每名其余横置角色（包括使用者自己）作为传导受击者估值。技能只要复用 `score_target_effect()` 即自动获得同一安全判断。
- 【火攻】本回合对某目标未实际造成正数伤害时记录该目标；同一使用者在自己的本回合内不会再次对该目标使用【火攻】，进入该使用者下一回合时清除记录。
- 【桃】出牌阶段自愈复用无名杀 `target_use` 的“吃掉还是留给队友”口径，由卡牌自身覆盖 `modify_ai_action_score()` 实现，AI 层无桃专属分支。判定采用无名杀的**保留分（keep）累加器**，而不是单一阈值。**照常回复自己**的三种情况：场上不存在“把我当队友”（他人对我态度 `>0.0`）的存活角色；自己体力 `≤1`（先保证自己不被击杀）；自己是领袖且体力 `<3`（领袖阵亡即终局）。其余情况先取保留分初值 `2.0`，再分两步修正：①友方领袖体力 `<3` 时保留分固定为 `3.0` 并**直接判定留桃**（该分支早于稀缺降级，不受自己手牌影响）；②否则若自己手上的【桃】数量不超过体力的一半（`2 × 桃数 ≤ 体力`），保留分降级为 `1.0`，让桃少时优先自保。随后对每名“我对他的态度 `>2.0`、体力 `<3` 且体力低于我”的队友按 `我体力 − 队友体力` 累加保留分，最终严格大于 `2.0` 即判定留桃。判定为留桃时动作分扣 `8.0` 并夹到 `-0.01`，低于策略层的动作接受阈值 `0.0`，AI 便主动结束出牌阶段而不消耗这张【桃】。效果上，手上只有一张桃时只会为“比我低至少2点体力的铁杆队友”或残血领袖留牌，而手上桃数超过半血容量时会为只差1点体力的队友留牌。该判定只读取权威快照、自己可见手牌与身份态度，不改变回复量 `1` 点、目标规则、濒死救援顺序或任何规则状态。
- 统一选择器会为弃牌阶段枚举固定数量组合，默认最多 `256` 组；丈八响应材料也选择保留价值最低的合法手牌。

无懈可击按当前奇偶状态计算净收益：原锦囊对目标有利时，希望其生效；原锦囊对目标有害时，希望其失效。判断统一读取全部锦囊自身的 `target_result`、动态逐目标结果和 `modify_ai_negation_effect_utility()`，再按响应者对目标的当前态度换算，不能只读取静态 `target_result` 或为少数牌名另建分支；因此【铁索连环】对已横置目标的解除连环按正收益 `+0.5` 处理，【借刀杀人】也能识别队友借刀的团队收益，新增锦囊只需正确声明 AI 元数据即可进入同一收益计算。净收益会扣除【无懈可击】当前保留价值的 `0.12` 倍；仅剩最后1张时，非关键锦囊收益先乘 `0.45`，再扣除 `1.5` 分储备价值，关键牌效只扣 `0.5` 分储备价值。阶段跳过、足以令目标立即濒死的伤害、至少摸 `2` 张牌、1体力及以下的回复，以及通过 `effect_id=discard_target/steal_target` 拆取或获得高价值资源都属于关键牌效，不套用 `0.45` 倍率；高价值资源阈值固定为 `5.0`，只读取公开装备与响应者自己的可见手牌、木牛“粮”，不窥探其他角色隐藏手牌。重复持有【无懈可击】时不扣最后一张储备价值，卡牌自身 `[6,4,3]` 的递减保留价值也会促使AI使用多余副本。

【闪电】的无懈收益额外乘 `0.10`，反映低概率命中与未命中后继续传递的特性。若原锦囊目标就是响应AI本人，且【万箭齐发】已有至少1张【闪】、【南蛮入侵】已有至少1张【杀】、【决斗】已有至少2张【杀】，无懈收益再乘 `0.20`，优先使用直接响应资源。以上修正只调整资源倾向，不改变无懈奇偶链、动态牌效或身份态度；同步 `should_negate()` 与异步选牌请求统一调用 `score_negation()`，不得维护两套阈值。

若正态度队友对响应者本人使用动态结果为负的锦囊，第一轮固定保留【无懈可击】，相信队友具有战术意图；该规则只覆盖“原锦囊尚未被抵消”的首轮判断，不改无懈奇偶链。下一张无懈会翻转状态，因此反无懈继续使用同一效用公式。

主动转化技能通过 `SkillDefinition.build_ai_virtual_card_action()` 返回实际生成的只读 `use_card` 代理；丈八蛇矛等装备自定义动作使用 `CardDefinition` 的同名接口。`BasicAIPolicy` 只把完整代理评分相对通用基础评分的差额合并回原动作，因此目标牌效不会重复计算，但卡牌专属修正、防具完全拦截判断与【疾雨】【星火】【还阳】等 `modify_ai_card_action_score()` 收益会自然生效。当前【安打】【罡风】【全垒】【倾力】【传冲】与【丈八蛇矛】均接入该协议。【全垒】还比较普通材料【杀】与雷【杀】在相同目标下的收益差；转换增益按 `1.0` 倍抵扣材料静态成本，所以普通【杀】被藤甲拦截而雷【杀】有效时会主动转化。

补充的队友决策保护适用于原锦囊尚未被抵消的首轮：当锦囊来源是响应者的正态度队友，且目标为该来源自己或该响应者本人时，AI一律不使用【无懈可击】，不因静态或动态牌效为负而推翻队友的主动选择。该保护不适用于敌方来源，也不适用于已经被无懈抵消后的反无懈；后者仍按奇偶效用恢复队友锦囊的生效。

替他人挡灾的保护性响应还必须跨过明确队友门槛 `PROTECTIVE_NEGATION_ALLY_ATTITUDE_THRESHOLD=3.5`：首轮抵消有害锦囊与反无懈恢复有益锦囊都属于“替目标挡灾”，当目标不是响应者本人、态度为正但低于 `3.5` 时，`score_negation()` 直接返回负值，AI 固定放弃该张【无懈可击】。门槛存在的原因是内奸制衡反贼 `1.0`、反贼结盟内奸 `3.0`、领袖笼络内奸不高于 `3.0`、忠臣容忍内奸不高于 `3.0`，以及身份标记最低置信度 `0.5` 折算出的“推测友方”不高于 `3.0`：这些角色并非响应者的同阵营队友，替它们令锦囊失效等于帮助敌方保留出牌与摸牌阶段。以判定区【乐不思蜀】【兵粮寸断】为例，旧口径在响应者持有两张及以上【无懈可击】时净收益可达 `+0.72`，AI 会替敌方解控；加入门槛后同一场景固定返回负值，完整对局链路中反贼 AI 不再响应内奸判定区的【乐不思蜀】。态度达到 `3.5` 的同阵营目标仍按原奇偶收益保护，例如反贼对反贼 `5.0`、领袖对忠臣 `6.0`、忠臣对领袖 `10.0`、响应者本人 `10.0`。攻击性响应（抵消敌方收益锦囊、反无懈恢复敌方受损效果）的目标态度为负，不进入该分支，仍由通用效用与身份态度决定。

## 六、技能 AI

- 【无邪】固定确认对自己或正态度队友的回复，拒绝帮助敌方；虎克评估多目标伤害牌时，为每名友方受击目标加入可回复 `1` 点体力的补偿，从而抵消可被技能修复的友伤负收益。
- 【飞焰】手牌不多于 `2` 张且至少有 `1` 张牌时优先选择自己作为【火攻】目标，以展示并弃置同一张牌稳定命中；手牌较多时按身份态度优先选择敌方，并把摸 `3` 张牌与本回合四个主要阶段直接转换得到的共 `4` 个普通出牌阶段计入高行动收益，不把它们估作额外阶段。视为使用的【火攻】会携带扩展存储 `{"source_skill_id": "feiyan", "hit_reward_value": 7.8}`（`hit_reward_value = 3 张牌 × 1.0 + 4 个出牌阶段 × 1.2`），该值传递到【火攻】的展示与弃牌请求，是“对自己使用火攻也值得弃牌”的唯一收益来源；没有它时【火攻】只会按统一评分看到约 `-11` 的自伤惩罚并一律取消，飞焰的摸牌与阶段转换也就永远无法触发。
- 【幽锋】强制选目标时优先敌方低体力、低护盾与高威胁角色；敌我态度权重为 `1.6`，以常见 `5` 点体力加护盾生存为基准的脆弱度权重为 `1.2`，目标威胁按 `0.35` 加入。弃置敌方区域牌时优先高价值牌，若被迫选择友方则优先低价值牌；隐藏手牌固定按未知资源 `2.0` 估值，不读取真实牌面。
- 【掠袭】让AI对自己猎物的用牌动作增加 `2.5 - 目标态度×0.45` 的直击与集火价值；合法动作仍由规则层的距离固定为 `1` 和目标响应限制生成，评分不能制造非法目标。
无名杀武将技能通常在技能定义内同时提供 `check/order/result/effect`。本项目对应规则是：技能效果与配套 AI 必须写在同一个 `game_data/skills/*.gd` 文件中。

`SkillDefinition` 提供：

```gdscript
func score_ai_action(authoritative_snapshot: Dictionary, action: Dictionary, evaluator: Object) -> float
func score_ai_choice(authoritative_snapshot: Dictionary, choice_request: Dictionary, action: Dictionary, evaluator: Object) -> float
func modify_ai_card_action_score(authoritative_snapshot: Dictionary, action: Dictionary, current_score: float, evaluator: Object) -> float
func modify_ai_incoming_card_effect(authoritative_snapshot: Dictionary, actor_id: int, target_id: int, definition: Dictionary, ai_profile: Dictionary, target_result: float, expected_damage_amount: int, current_score: float, evaluator: Object) -> float
func modify_ai_lethal_damage_consequence(authoritative_snapshot: Dictionary, actor_id: int, target_id: int, current_score: float, evaluator: Object) -> float
```

- `score_ai_action()`：主动技能是否值得发动。**基类默认返回 `0.0`**，因此任何实现 `append_play_phase_actions()` 的技能都**必须同时覆盖本方法**，否则AI会把该动作视为毫无价值而**永不发动**：技能会安静地在整局中一次都不出现，且不产生任何报错。这类遗漏只能靠“整局动作总数”之类的AI行为回归发现，技能自身的 `score_ai_choice()` 测试会全部通过。【解构】与【灵感】都曾因此完全不被AI使用——AI从不发动【解构】，就永远不会记录牌名，也就谈不上使用【灵感】。
- `score_ai_choice()`：技能创建的确认、选牌、选目标或牌目标组合如何选择。它只在请求已经创建之后才生效，**不能**替代 `score_ai_action()`——不发动的技能永远走不到这一步。
- `modify_ai_card_action_score()`：被动、锁定或触发技能如何改变持有者使用某张牌的价值。
- `modify_ai_incoming_card_effect()`：目标当前技能如何改变其受到本牌后的预期结局；例如致命伤害会触发【求生】时，用“存活至1点体力并弃置全部手牌”替换普通击杀收益。评估器按目标固有、模式、临时与局内技能依次调用，同一技能ID只执行1次；属性连环中的每名传导目标也使用同一钩子。
- `modify_ai_lethal_damage_consequence()`：行动者自身技能如何改变“由它击杀该目标”的规则后果，例如把击杀奖惩整体改写为摸四张牌。它由 `IdentityStrategyEvaluator.score_lethal_damage_consequence()` 在基础身份结论之后调用，按行动者固有、模式、临时与局内技能依次执行，同一技能ID只执行1次，领袖技只在行动者身份确为领袖时参与。钩子只允许读取快照并返回修正后的累计分，不得执行规则效果、不得创建请求，因此“规则侧改写”与“AI 侧预估”必须共用同一份判定条件。

转化技能按实体 UID 查询材料时统一使用 `NonameAIEvaluator.get_owned_card_by_uid()` 与 `get_owned_card_value_by_uid()`。两者覆盖本人普通手牌、木牛“粮”和公开装备区；装备材料的机会成本优先读取卡牌 `equip_value`，缺失时才回退普通 `value`。因此把八卦阵等场面装备作为材料不会被误估为未知牌2分，材料花色、颜色和定义 ID 也能进入技能专属评分。

判定型技能通过规则请求的 `judgment_ai_context` 向【戏法】等改判定 AI 暴露结果方向：`favorable_condition/unfavorable_condition` 支持颜色、花色、点数范围和递归 `not`；`favorable_result_player_values` 表示有利结果对各角色的原始正负价值；`preferred_suit_values` 用于【投狭】等没有简单成功/失败的多花色收益。多花色收益仍需结合角色价值判断阵营方向：友方改判定者追求高收益花色，敌方改判定者优先选择未登记花色或把全部已知命中牌置底。改判定 AI 只对已经观看到的牌排序，不能修改牌面、伪造判定或绕过最终规则。

主动技能合法动作必须把 `skill_id` 写入 `payload`。零材料确认请求必须在上下文声明 `ai_allow_confirm=true`，否则合法动作中只有取消，不会凭空生成确认。

单材料转化技能必须先按“逻辑牌定义 + 技能规则覆写 + 材料真实颜色”生成逐材料目标映射，再枚举材料与目标组合并执行完整虚拟牌校验。多材料转化技能与转化装备（【山倾】【丈八蛇矛】）必须先按 `VirtualCard.resolve_material_aggregate()`（或只读快照版 `resolve_suit_aggregate()`）聚合本次材料的花色与颜色，再生成“材料组合 → 合法目标”映射：全部材料同花色视为该花色，同色不同花色视为该颜色无花色牌，异色或含无花色材料视为无色牌。【罡风】【安打】【全垒】均遵循单材料流程：黑色材料不能指定拥有【琥珀】的角色，红色材料仍可按原规则指定；完整校验同时覆盖阶段【杀】次数，次数用尽时不得仍亮起转化【杀】类主动按钮。无材料转化类技能（如【倾力】）同样在 `can_activate` 与 `list_legal_virtual_targets` 中走完整虚拟用牌校验：`play_limit` 用尽时合法目标列表为空、技能按钮实时熄灭，不得仍亮着等待点击后失败。AI 不得先按无色虚拟牌生成动作、再依赖提交失败回退；候选阶段就应排除预知非法组合。AI 动作自带的 `card_color` 必须是同一次聚合结果，使通用评估器按真实颜色预判【琥珀】【仁王盾】等来牌限制。
【全垒】在此通用合法性基础上另有材料决策：材料本身属于普通、火或雷【杀】牌族时，相同目标下转化为雷【杀】的正收益差按1.0倍抵扣材料价值的0.45倍成本，普通【杀】被藤甲拦截而雷【杀】有效时因此会主动转化。两名目标的单独雷【杀】评分都严格为正时，双目标动作再额外加4.0分，保证AI利用“目标上限+1”同时攻击两名有利目标；任一目标为非正收益时不获得该奖励，不会为发动技能而强行误伤队友。

防酒杀AI参考无名杀公开源码 `libccy/noname` 提交 `e18a8256e01ab1357e4c7472349dceb3d0aa1a3a` 中 `card/standard.js` 的【杀】、【闪】响应评估：响应时直接读取真实 `damage_amount`，每多1点伤害给【闪】确认加4.0分，伤害不小于当前体力+护盾时再加8.0分致命奖励。因此致命酒杀不会为友方属性连环收益放弃【闪】；非致命连环仍保留原8.0分放弃响应修正。主动估值会把使用者公开 `wine_bonus` 转成预期伤害，每多1点伤害使目标与连环伤害效果倍率乘2.0，并按体力+护盾判定预期击杀。

弃牌与技能费用选择还会评估“最后1张【闪】”的防酒杀价值：只有敌对存活角色已有正数 `wine_bonus`、已知持有可提供 `sha` 响应模式的牌，且根据座次、坐骑与公开武器范围能够命中本人时才加分；非致命威胁加2.0，致命威胁加6.0。多名威胁者取最高值而不累加，防止牌值无界膨胀。

“横置一名角色”类技能按状态切换估值：对未横置目标计算变为横置的收益，对已横置目标计算恢复竖直的收益。【铁壁】【坚垒】不会因为目标已经横置而移除候选，AI 会结合目标态度和当前连环状态判断本次切换方向。

`PlayerState.to_dict()` 的公开快照包含只读 `skill_history`，用于【冰封】这类“每回合每名角色限一次”的 AI 判断。记录只包含已经通过 `announce_activation()` 成立的技能 ID、回合号与可序列化上下文，不暴露技能私有运行时字典；取消、条件失效或未成立的效果不得写入历史。

## 七、统一选择策略

- 可取消请求：最高确认分必须大于0，否则返回 `confirmed=false`。
- 不可取消请求：无论分数正负都选择代价最低或收益最高的合法动作。
- 零材料布尔请求：同时枚举取消与确认动作。
- 目标文字复合请求：为每个合法“目标×`control_id`”组合生成一条动作，取消仍为独立未确认动作；策略必须同时比较两个维度，不能先固定目标再局部选择按钮。
- 零牌费用加目标请求：同时枚举“只选目标”和“选牌加目标”。
- 强制多选：枚举固定数量组合，默认上限256组。
- 弃牌阶段、技能费用：选择保留价值最低的牌。
- 过河拆桥、顺手牵羊、五谷丰登：选择已知价值最高的牌；隐藏手牌统一按未知资源估值，不猜牌面。判定区候选单独估值：弃置或获得敌方判定区牌固定记 `HOSTILE_JUDGMENT_DISCARD_VALUE = -8.0`（【闪电】再 ×0.6），友方判定区记 `FRIENDLY_JUDGMENT_DISCARD_VALUE = 6.0`（【闪电】同样 ×0.6），态度不明时按敌方值 ×0.5；因此 AI 不会优先拆掉敌人身上的延时锦囊。
- 火攻展示：目标展示最低价值手牌；火攻弃牌：伤害敌方收益高于同花色费用时才支付。**使用者对自己使用【火攻】时由本牌的 `score_ai_choice` 接管**：上下文带 `card_definition_id = "huogong"`（统一评分据此定位本牌评分），并原样携带虚拟牌 `virtual_storage` 中的 `hit_reward_value`；仅当“选择种类为 `fire_attack_discard` + 动作为确认 + 目标就是使用者本人 + `hit_reward_value > 0` + 使用者存活且体力大于 `1`”五条同时成立时返回 `hit_reward_value + 自身身份态度 - 自伤体力成本`。自身身份态度项用于撤销统一评分对自伤计入的固定惩罚（目标为自己时该项恒为正，让总分约为 `-11` 而必然取消），自伤体力成本为 `1 × HP_RESOURCE_VALUE(2.0) = 2.0`，持有【无邪】且未满体力时归零。任一前提不成立即返回 `0.0`，普通【火攻】与他人造成的【火攻】口径完全不变。
- 水淹七军：比较全部装备总价值与1点伤害风险，1点体力时伤害风险最高。
- 响应【闪】、【杀】、【桃】、【酒】：按生存收益与牌成本决定；仅当横置响应者承受友方属性伤害、全部存活敌人也横置且自身不会被该段伤害打至濒死时，【闪】额外扣 `8.0` 分并选择让连环传导，否则请求候选仍由规则层限制。
- 濒死【桃】/【酒】响应：额外应用忠臣救领袖、反贼拒绝救领袖、多人局内奸保护领袖、内奸扶弱和低体力保桃逻辑。

### 机缘选择与局内技能

- `OpportunitySystem` 只把当前 AI 角色本人的三张私有候选交给机缘估值，不读取其他角色候选，也不把候选写入 `BasicAIPolicy` 的长期缓存。品质基础分依次为灰0、绿2、蓝5、紫9、橙14、红22；灰色不在随机候选中。摸牌每张加1.5分，已损失体力按每点3.0分提高回复价值，额外手牌上限每点加2.0分，额外回合每回合加8.0分；摸牌阶段额外摸牌每点加5.0分，【杀】次数上限每点按当前手牌加1.0或3.0分，伤害+1按至多3名敌对角色每名2.0分估值。
- 全部参与者同时开放机缘选择，AI 与真人在同一 `choosing` 阶段并列待提交，不存在 AI 等真人先选或真人等 AI 先选的先后关系。各自选择模式下，进入 `choosing` 的同一调用栈内连续完成全部待提交 AI 的估值与记录，不在每名AI选择前生成完整观察者快照；投票模式为让全部真人先收到同一“可投票”状态，AI 选票延后一帧统一提交（`call_deferred`），回调内仍逐票经过同一候选估值与待提交集合校验。两种时序都不改变候选顺序、评分公式、随机源、公开完成列表或逆时针效果顺序。估值异常返回空候选时，AI 保留在待提交集合中，由停滞看门狗按同一 `choose_for_managed_player()` 入口代选，不伪造票面或卡面。
- 获得技能默认追加6.0分；若同一稳定技能 ID 已经安装则扣12.0分，避免选择不会重复生效的技能卡。伤害、失去体力、弃牌、获得敌方牌等负面目标效果在存在敌对在场角色时加5.0分，没有敌对目标时扣8.0分。新增的【祥音】（绿）、【聚寇】（蓝）、【光覆】（紫）与【血仇】（橙）四项技能机缘沿用同一 `grant_skill` 估值分支，不新增机缘专用评分：它们获得的都是既有武将技能，安装后立即由各技能文件的 `score_ai_action()`/`score_ai_choice()` 与【血仇】的濒死来牌估值修正接管后续决策。
- 批量弃牌、比例失去体力/上限、当前体力伤害和轮末离场继续优先敌方；交换手牌、装备或武将牌优先选择对应资源较少的友方与资源较多的敌方。群体虚拟锦囊按敌方与友方有效目标数量差修正；弃牌后摸牌按自身判定区负担提高价值；全场装备、每人随机三张、不同名延时锦囊和手牌视为牌按可获得实体数或当前手牌数增加收益。
- 机缘效果后续创建标准目标或区域选牌请求时继续复用统一选择策略：负面目标优先敌方，正面目标优先本人或友方，隐藏手牌仍按未知资源估值。AI不绕过 `ChoiceRequest`、牌区候选或权威目标校验。
- `PlayerState.acquired_skills` 中的技能 ID 会加入 AI 当前技能集合，因此局内获得技能继续使用各技能文件自带的 `score_ai_action()`、`score_ai_choice()` 与卡牌联动修正；每回合次数与累计次数由控制器统一复核，AI评分不得自行返还或超用次数。

## 八、调度安全与数值

- 卡牌与武将静态元数据缓存最多按实际查询到的定义种类增长；缓存内容来自数据库独立副本，只读且不跨模块共享可写引用。同一批候选的技能 AI 实例按稳定技能 ID 复用，动作选定或选择结束后立即释放，不跨决策保留。
- 单次 AI 决策的玩家快照索引只在本次同步调用栈内存在：身份观察完成固定前置同步后，索引构建额外遍历最多10名玩家1次；玩家 ID、存活人数、身份人数与领袖定位随后使用常量时间查询，局势值只在首次读取时计算1次。普通行动、统一选择、无懈判断和装备材料排序结束后统一释放。该索引不改变任何态度公式、卡牌价值、目标收益、响应阈值或玩法数值。
- `GameSettings.ai_response_delay_seconds` 默认 `0.30` 秒，可在 `0.10` 至 `1.00` 秒之间以 `0.05` 秒调整。
- `GameSettings.game_speed_interval_seconds` 默认 `0.30` 秒，可在 `0.10` 至 `1.00` 秒之间以 `0.05` 秒调整。AI 普通行动等待它与 `ai_response_delay_seconds` 的较大值，响应牌与同时无懈先经过流程间隔发布提示，再开始同一较大值的AI等待。
- 单个 AI 出牌阶段最多执行 `64` 个动作，超过后强制结束。
- 多选 AI 默认最多枚举 `256` 个固定数量组合，可在检查器调整为 `16` 至 `1024`，步长 `16`。
- 所有已接受动作、主动技能和普通选择结束后都进入统一 AI 进度恢复出口：优先安排当前普通选择，其次重建仍合法的 `chooseToUse`，最后安排下一次 AI 动作，避免同步技能在提前返回分支遗漏续接。
- AI 响应延迟结束后重新枚举最新合法动作，并逐项检查当前 `chooseToUse` 是否仍能表达这些动作：技能必须存在于 `button_ids`，普通用牌/重铸必须存在于 `card_ids`，装备主动动作必须存在对应装备本体 UID。若【传冲】等动态技能在旧请求建立后才变为合法，控制器系统取消旧请求并立即重建，再于同一次 AI 驱动中决策；不得先提交过期快照、输出“当前出牌选择已经失效或所选卡牌不合法”后再等待一轮响应延迟。
- AI 普通选择先提交策略结果；失败时从规则层完整合法动作枚举中选择确定性回退动作，保留固定组合、响应技能 ID 和各选择维度。默认最多重试 `2` 次，可在检查器设为 `0` 至 `5` 次；仍无法提交时只中断该无解请求及其事件、释放对应暂停令牌并恢复父流程，不中断整局。
- AI 与延时等待使用不在暂停期间累计的场景树计时器；同时【无懈可击】的 AI 计时器到期时若玩法树仍暂停，会保留同一请求并重新等待，恢复后继续提交，不能遗留询问而卡住结算。
- 阶段令牌、请求 ID、事件 ID 和对局 ID 共同阻止旧 AI 任务向新阶段或新请求提交。
- 正式无懈同轮多个 AI 并行等待，最先到达且通过权威校验者生效；无 `match_id` 的规则测试按行动顺序确定性裁决。
- 局域网真人在对局中掉线时，房主为同一稳定玩家 ID 注册 `BasicAIPolicy`，不重建身份、武将、体力、手牌或次数状态；若正在选将、普通选择、同时无懈或出牌阶段，则从该现有请求与统一调度出口继续。真人主动提交 `set_auto_managed` 也复用完全相同的注册、选择和出牌路径；取消手动托管时注销策略，掉线托管则保持到对局结束。该托管没有额外数值修正，仍使用当前0.10至1.00秒、步长0.05秒的AI响应设置、64动作上限和全部权威合法性校验。

### 开局自选与手气卡AI

- 真人最终自选确认时，控制器先按当前预览投射座次身份，再只应用该真人的武将；AI随后依剩余名额确认时遵守同一一次应用流程。AI不得在最终完成阶段再次改写已经展示的座次或武将。普通多目标或目标数加成的虚拟【杀】交给控制器的目标数组可按策略排列，但权威出口仍会按使用者下家起的顺时针顺序结算。
- 全武将座次身份自选开启时仍先执行第一次身份下的领袖选将；领袖技武将固定在普通随机候选之前，但AI首任领袖在本次全部合法候选中使用本局随机源选择，固定前缀不形成取将优先级。该首次AI动作只公开武将，不占用最终座次或身份名额；最终自选严格按房主设置张数生成其他玩家候选。真人提交有效座次身份预览时，控制器不提交AI最终选择、不消耗换将卡也不占身份名额；它会清空所有未确认AI的背景武将，只在一号位由AI补位时为该AI领袖选择一张公开预览武将。进入最终自选后，AI不会与真人同时抢占名额；控制器每轮都先等待全部真人确认，再按剩余名额自动选择。当前AI领袖已有公开预览武将时，AI最终确认必须提交该同一稳定武将ID，不能重新从随机候选取牌。若一号位与领袖均空缺，同一AI优先同时取得二者；其他AI从剩余非一号位和非领袖身份中依次选择。AI不自动消耗换将卡，最终提交仍经过 `CharacterSelectionService` 权威校验。
- 首任AI领袖的公开武将已经写入最终选择，因此进入最终自选后不会为该玩家重新发随机候选；它只以该稳定武将ID确认剩余座次与身份。`get_pending_player_ids()` 在领袖阶段返回该AI以完成首次亮将，在最终自选阶段继续返回尚未取得座次身份的该AI，但控制器检测到仍有真人待选时会停止AI驱动。该优先级高于一号位AI公开预览和普通候选筛选，保证预览、最终确认与开局桌面使用同一武将，同时不抢占真人名额。
- 全部真人完成后，控制器会把“保留首任领袖公开武将且尚未确认座次身份”的AI置于自动确认队列首位；一号位与领袖仍空缺时，该AI必须先以同一稳定武将ID确认二者。只有真人已经确认领袖时，其他AI才可先按剩余名额完成，首任AI领袖随后不改武将地确认剩余身份。
- 房主调整AI武将属于人工权威阶段，AI不自行覆盖房主选择。每次房主点击AI角色都会由共享对局随机源按房主锁定的1至20张普通候选数重新生成；房主结束后才安装最终武将技能。
- `StartingHandMulliganService` 只负责手气卡张数、完成状态和起手估值。后置比例为 `(座次-1)/(总人数-1)`，防御需求从一号位1.0分线性增加至末位2.5分；【闪】1.0分、【桃】1.25分、【酒】0.75分、防具1.0分、防御坐骑0.5分。总牌值低于每张平均3.5分也刷新；同名牌数组价值按边际项递减。AI关闭时立即保留，有限模式不超过设置张数，无限模式每名AI最多20次安全尝试。该组件不移动卡牌、不读取UI、不推进阶段。
- 全部AI与真人完成手气卡后，控制器会先把权威阶段切换为 `round_start`，再派发首轮 `roundStart`。因此该时机创建的AI或真人技能选择不再与已结束的手气卡提示共用阶段；AI选择仍由统一选择调度处理，不会重新进入或阻塞手气卡服务。

## 九、替换策略

自定义策略至少实现：

```gdscript
func choose_action(authoritative_snapshot: Dictionary, legal_actions: Array[Dictionary]) -> Dictionary
func choose_card_choice(authoritative_snapshot: Dictionary, choice_request: Dictionary, legal_actions: Array[Dictionary]) -> Dictionary
```

返回值必须可序列化，并最终通过 `PlayerAction` 和 `ChoiceResponse` 权威校验。搜索树、效用系统、行为树或模型推理可替换 `BasicAIPolicy`，但不能直接调用伤害、摸牌、移动牌或阶段推进函数。

- 强制弃牌保留【桃】并选择低价值组合。

## 十一、本轮卡牌估值补充

- 【白银狮子】在装备区离开且持有者受伤时，规则回复持有者 `1` 点体力。`score_baiyin_equipment_loss_recovery()` 按“1点体力=2点资源”并结合敌我态度计入弃置、获得和费用选择：拆取受伤敌方会减少收益，移除受伤友方会增加收益；获得新白银狮子以替换自身同名防具时也计入该回复。其防具AI接口同时把单次预期承伤封顶为 `1`，因此普通2点以上伤害、酒杀和属性传导都不会继续按高额伤害放大收益；无视防具的【杀】不应用该上限。手牌、满体力、死亡或非白银狮子不产生离区回复修正。
- 【铁索连环】在1v1时固定重铸；三人及以上才按本次实际横置或解除横置估值。对横置敌方解除连环、对未横置友方施加连环均为不利目标，每名额外扣 `0.75` 分；双目标只有整体收益仍为正时才保留。
- 出牌阶段【酒】不回复体力，只令本回合下一张【杀】伤害基数由 `1` 提高到 `2`。AI只读取本次 `chooseToUse` 已经通过阶段次数、目标、距离、防具与技能限制的合法【杀】动作，不能因为手里仍有一张本阶段已不能使用的【杀】而喝酒。策略先取得所有合法动作的完整直接评分，再计算“酒后该【杀】的完整评分 + 实际增伤 - `AI_WINE_CHAIN_CARD_COST = 0.5`”；该链路必须严格高于对应直接【杀】（同分只加 `AI_WINE_BEFORE_SLASH_PRIORITY = 0.01` 的稳定排序分）、酒杀总收益为正且增伤为正，才会选择【酒】。因此即使【杀】在动作列表中排在【酒】之前，AI仍会先酒后杀；没有可执行后续【杀】时固定保持负分并直接结束出牌。白银狮子把两者承伤都封顶为1时边际收益为0，AI直接使用普通【杀】而不酒杀。没有真实正边际时先扣 `AI_WINE_WITHOUT_SLASH_PENALTY = 4.0` 分，再钳制到不高于 `-0.01` 分，避免动态保留价值反向抬成正分；濒死自救仍回复本人 `1` 点体力。
- 【过河拆桥】【顺手牵羊】在目标仅有判定区牌（无手牌、无装备）时单独修正主动使用分：敌对目标 `-4.0` 拒绝打出，友方目标至少保留 `2.0` 正分鼓励解控，态度不明 `-2.0` 保守拒绝；避免“拆掉敌人乐不思蜀”这类负收益动作进入出牌阶段。
- 【桃园结义】只对受伤存活角色创建逐目标结算和无懈链，每名回复 `1` 点体力；无有效目标时AI额外扣 `4.0` 分，避免无效群体结算。

## 十三、新武将 AI 规则

- 【星祈】只要观看牌中存在锦囊候选，AI 对确认动作固定增加 `10000.0` 分并始终发动，再按卡牌价值选择具体锦囊与友方缺牌程度选择获得者；该分值只覆盖首步可取消判断。排序先按判定区处理：自身有【乐不思蜀】时优先把红桃置顶，有【兵粮寸断】时优先梅花，有【闪电】时避开黑桃 `2` 至 `9`；没有可通过的判定牌时把已知牌全部置底。其余情况下按卡牌价值安排，优先保留基础摸牌阶段预计摸取的 `2` 张。规则层观看牌中若无任何锦囊时，直接跳过“选择锦囊”与“选择获得角色”两步并进入牌堆顶底排布，避免空候选卡死。
- 【星落】只会枚举选 `1` 名或选 `2` 名其他有手牌角色；没有合格其他角色时不生成主动技能动作。自身优先重铸低价值牌，友方目标偏向换掉低价值牌，敌方目标只计较小的手牌结构干扰收益。已知同为锦囊或红色时，追加摸 `2` 或摸 `1` 的组合收益。
- 【弦奏】优先消耗本轮尚未使用、当前回合价值较低的花色。摸牌阶段通常保留正常摸 `2`；弃牌阶段在手牌数低于当前体力时提高发动评分；判定区存在延时锦囊时提高跳过判定阶段评分。
- 【安可】在持有者存活在场且本轮额度少于 `3` 时，将额外完整回合作为高正收益确认；四花色统计只接受希露瓦自己回合内进入弃牌堆的黑桃、红桃、梅花、方块实体牌，回合外不计算也不显示文本。
- 【倾力】使用标准雷【杀】动作评分并扣除失去 `1` 点体力的资源值；主动入口 `can_activate` 通过 `validate_virtual_use` 复核阶段【杀】次数与距离，次数用尽时按钮熄灭且不生成动作。【强攻】仅对敌对目标比较红色直击、黑色增伤或武器双收益与弃牌保留价值。上述评分只影响决策，不修改实际数值。
- 【焕发】只把“摸一张牌 + 额外出牌阶段”交给正态度目标；敌方或中立目标固定返回 `-20.0` 分。确认收益为“摸 `1` 张牌的固定 `1.0` 资源值 + 额外出牌阶段价值”之和再乘以态度并除以 `5.0`，因此空手友方仍然保留摸牌的固定正收益；只有阶段价值部分要求至少存在1个当前可执行的出牌机会：已用过【酒】、回复条件不满足、场上没有可操作区域牌、没有其他持武器角色或只有响应专用牌时只不增加阶段价值，不再把整次确认判为负分。
- 【剑势】对敌方目标确认固定加 `100.0` 分，对友方或非敌对目标固定减 `100.0` 分。红色有利条件向改判定 AI 写入技能来源 `+2.0`、伤害目标 `-2.0` 的角色价值；该上下文只决定是否把红牌保留在顶端，实际红色结果仍固定令当前目标伤害 `+1`。
- 【山倾】先复用普通【杀】的完整目标、防具、响应、属性与被动技能评分，再按去重花色追加收益：方块按摸 `1` 张计分，红桃按预期回复 `1` 点计分，梅花在目标存在区域牌时按基础控制值 `1.5` 与态度满量程 `5.0` 规范化计分；每张材料扣其保留价值的 `0.45` 倍。黑桃无距离已经在合法动作枚举阶段生效，AI不会生成远距离非法目标。装备材料读取真实 `equip_value` 与花色。同花色材料不会重复增加收益。两张材料的聚合花色与颜色在材料枚举阶段算出并写入动作 `card_color`：全部同花色视为该花色，同色不同花色视为该颜色无花色牌，一黑一红视为无色牌；因此两张黑色牌不会生成指向拥有【琥珀】角色的动作，红黑混合与两张红牌的组合仍正常生成。梅花弃牌选择对敌方取最高价值牌；若其他收益使友方成为目标，则取最低价值牌减少友方损失。
- 【戏法】只要能发动，确认动作固定加 `100.0` 分。判定有利结果对判定角色的基础价值分别为：【八卦阵】红色 `2.0`、【兵粮寸断】梅花 `3.0`、【乐不思蜀】红桃 `4.0`、【闪电】避开黑桃 `2..9` 为 `6.0`。对友方选择有利条件、对敌方选择不利条件；【剑势】另按来源与目标相反价值汇总。若两张已知牌都不满足期望条件，则全部置底尝试未知牌。同条件下优先把基础价值较高的牌留在顶端，减少关键牌被无谓置底的机会成本。面对【投狭】时，同阵营优先命中最高价值可回收花色，敌对阵营优先把不匹配花色置顶；两张均匹配时全部置底尝试未知牌。
- 【投狭】对友方回合确认基础分为 `8.0`。敌方回合只有本回合出牌阶段弃牌中存在基础价值至少 `6.0` 的关键牌才确认，达到阈值后保留 `1.0` 的正分余量；否则返回 `-8.0`。判定前把每种可回收花色的最高牌值写入 `preferred_suit_values`，【戏法】先将花色收益乘 `100.0` 决定目标花色，再用判定牌自身价值处理同分。获得选择把候选牌价值乘 `2.0`，没有正收益牌时可取消；当前回合角色最终摸 `1` 张属于真实规则，不由 AI 分数改变。
- 【追歼】对每条合法“费用牌+目标”动作计算 `-目标态度×0.7 + 横置奖励1.0 + 基础1.5 - 费用牌价值×0.35`。因此通常选择敌方、横置目标与低价值费用；友方高态度或昂贵救命牌会使确认分不高于取消。成功后只在目标武将牌写入来源唯一的“追歼”提示，不创建或消费 `zhuijian:<source_player_id>` 公开标记；通用AI读取同ID的提示条目，在来源被视为友方时对该目标的火焰、雷电伤害追加 `+4.0` 分。评分只预测可见的持续效果，不伪造伤害目标或保证提示一定触发。
- 【秘策】为每个合法目标同时枚举“出牌阶段”和“弃牌阶段”两项。额外出牌阶段把目标每张公开手牌按 `0.65` 分计入、最高 `5.0`，再为每张完整快照中已知可主动使用牌增加 `0.9` 分，最终乘佩拉对目标的 `态度/5.0`；因此友方牌多时提高收益，敌方牌多时降低收益。摸1张并额外弃牌先计算 `discard_count=max(手牌数+1-手牌上限,0)` 与净牌差 `1-discard_count`，交给统一资源估值：敌方超限越多越有利，友方低于上限时每点空余容量再增加 `态度/5.0×0.15`。两段收益求和后严格大于0才发动，因而可把弃牌阶段交给超限敌人、把出牌阶段交给手牌充足队友，也会把另一项对佩拉自身的收益同时纳入。
- 【勘测】观看目标按敌方每张手牌 `0.18×(-态度/5.0)` 计算信息价值，通常优先敌方多手牌角色。属性【杀】基础值为 `2.2`，每名敌对存活角色追加 `0.45`、总追加最高 `1.8`；【桃】基础值为 `1.2`，玲可已经受伤时追加 `4.0`，体力低于2时每少1点再加 `1.5`。玩家两步选择与AI直接动作复用同一目标和牌类估值，规则端仍只从牌堆取得实际存在的首张匹配牌。
- 【勘测】还声明 `ai_extra_play_phase_value=1.4`，供【焕发】等“把额外出牌阶段交给角色”的通用评估识别其每个新出牌阶段可额外发动1次的价值；该元数据只参与阶段赠予决策，不会增加勘测自身的发动次数或实际获得牌数。
- 【求生】通过 `modify_ai_incoming_card_effect()` 处理预计致命来牌：仅在AI完整知道玲可全部手牌、手牌至少1张、其中无【桃】【酒】，且 `体力+护盾<=预计伤害` 时生效。钩子移除普通击杀倍率和身份死亡奖惩，改用单次基础伤害的态度收益，再加入“玲可失去全部手牌”的统一资源变化；直接目标与属性连环传导目标都使用同一修正。手牌牌面不完整时保持普通估值，禁止猜测隐藏牌后认定求生必定发动。
- 【血仇】处于①时，AI评估预计致命来牌会把进入濒死后的 `X` 点回复纳入结果，不把万敌直接视为必死目标；回复后的体力最低按 `1` 处理且不超过当前体力上限。②不提供回复，因此保持普通濒死与击杀估值。
- 【弑神】为万敌使用【杀】的每名目标加入固定伤害 `+1` 的收益；依需求指定策略，不因逐目标失去 `1` 点体力降低使用【杀】的意愿，因为【血仇】承担濒死恢复。合法动作仍须遵守“前X张”的实际使用序号，AI评分不能为第 `X+1` 张制造距离或次数例外。
- 【聚寇】零材料确认按伤害来源与赛飞儿的态度决定：赛飞儿本人或赛飞儿队友固定得到 `+100.0` 分并确认，敌方固定得到 `-100.0` 分并取消。该规则对①摸 `1` 张和②获得 `1` 枚“币”均相同，不读取或猜测隐藏手牌。
- 【换日】为每名合法其他角色各生成一个主动技能动作，以当前全部“币”数量作为预计伤害。统一资源评分使敌方目标为正收益、友方目标为负收益；无币、阶段次数已用或没有其他存活目标时不生成动作。评分技能同样是没有运行时宿主的临时实例，因此“币”数量必须从本次权威快照的 `public_marks` 读取，不允许调用 `host.call("get_player_mark", ...)`；同一技能并用 `_get_coin_count()`（运行时宿主）与 `_get_snapshot_coin_count()`（权威快照）两个读取函数区分两条路径。
- 【升变】优先选择已有“军功”的友方，并把军功优先分配给拥有“出牌阶段限一次”或“轮回技”技能的角色：这类技能每次发动都会推进军功积累，是【奇袭】阈值分支的主要来源。评分固定包含 `1.0` 正基础收益；已有军功的目标按 `8.0 + 本次实际获得量` 计，本次获得量按原文“至多获得至8枚”截断 X，角色持有总数不设上限、已有军功会持续累积；目标没有军功时按 `10.0` 计并同时计算“移除全场旧军功”对敌我双方的净收益，最后整体乘以 AI 对目标的阵营态度。技能优先价值为每个命中技能计 `2.5` 分、最多统计 `3` 项；命中技能从权威快照的固有技能、`mode_skill_ids`、`temporary_skills` 与 `acquired_skills` 四处按稳定 ID 去重后统计，判定口径与规则层完全同源：轮回技读取技能源码声明的轮回技标签，“出牌阶段限一次”按正文中未加引号的声明识别；因此目标身上的【奇袭】（正文只是带引号地提及两个标签）与只引用他人轮回技的技能都不会被误认为收益来源。评分技能是没有运行时宿主的临时实例，因此轮回数、公开军功和场上角色必须全部从本次权威快照读取；该技能在持有者每个回合开始时询问，合法时 AI 会正常确认。
- 【好戏】是欢愉技，没有出牌阶段动作，只在阿哈时刻演出时评估目标选择：动作分按统一资源尺度计算——X 张基本牌按 `CARD_RESOURCE_VALUE = 1.0` 每张计，每名敌方目标随机失去一张未知手牌按 `RECAST_DRAW_VALUE = 4.5` 计，友方目标按同等数值反向计入。因此“不弃置但取 2 张基本牌”得 `2.0` 分，“弃置 1 名敌人并取 1 张”得 `5.5` 分，“弃置 2 名敌人并不取牌”得 `9.0` 分；超过 2 名目标或包含自己时返回 `-20.0`。评分只影响目标选择，不改变随机抽取范围、`X = 2 − 目标数` 算式或实际弃置张数。
- 【连戏】的发动入口是**出牌阶段开始时的自动询问**（`phaseUseBegin`），因此**不生成主动技能动作**；AI 与玩家在同一个流程窗口中用同一套选项应答。“重铸”（界面文案，语义为继续重铸）按 `下一轮 Y 增量 × HP_RESOURCE_VALUE = 2.0 × AI_DAMAGE_VALUE_RATIO = 0.85 − AI_RECAST_QUALITY_COST = CARD_RESOURCE_VALUE × 0.35` 评分，只有下一轮确实能把 Y 提高 1 时才得正分（阈值落在第 `3`、`6`、`9` 轮：`2.0 × 0.85 − 0.35 = 1.35`），否则不如立即结束；“结束”（界面文案，语义为结束重铸并造成伤害）取全部存活其他角色中**最高**的伤害收益，伤害分按 `Y × HP_RESOURCE_VALUE × 0.85 × 最佳敌对目标态度强度（-态度/5.0）` 计算，伤害目标选择复用同一算式，友方目标得到负分因此不会被选中。以上权重只影响决策，不改变重铸至多 `MAX_RECAST_TIMES = 9` 次、`Y = ⌊重铸次数 ÷ DAMAGE_DIVISOR = 3⌋` 或实际伤害。
- 【凶星】是欢愉技，只在阿哈时刻演出时评估目标选择：目标分 = `AI_THREAT_WEIGHT = 1.0 × 威胁度 + AI_ATTITUDE_WEIGHT = 0.7 × 敌我态度`，选自己时额外固定 `AI_SELF_TARGET_SCORE = 12.0`；当自己体力上限为 `AI_SELF_PREFER_MAX_HP = 1` 且我方欢愉技数量比敌方多 `AI_SELF_PREFER_JOY_ADVANTAGE = 2` 或以上时优先选自己（此时自己不在可选目标中则回退 `AI_SELF_TARGET_FALLBACK_SCORE = -3.0`）。两侧欢愉技数量由 `get_side_joy_skill_count()` 从**静态武将元数据**统计（武将 → `skills` → `joy_skill` 标签，按角色ID缓存结果），**不读取运行时技能实例**：态度为正或0的角色计入我方、态度为负的计入敌方，中立角色不计入任何一方。评分只影响目标选择，不改变层数、伤害加成值、保护次数或角标口径。
- 【鸿运】是非欢愉技的回合开始前技能，AI 只决定是否确认发动：按敌我欢愉技数量差给出 `AI_DOMINANT_JOY_ADVANTAGE = 2`（优势阈值）、`AI_EVEN_JOY_ADVANTAGE_CEILING = 1`（均势上限）、`AI_EVEN_ADVANTAGE_SCORE = 5.0`（我方多 0~1 个且自身体力值少于上限）、`AI_DOMINANT_ADVANTAGE_SCORE = 8.0`（我方多 2 个以上且体力上限大于1）、`AI_HOSTILE_ADVANTAGE_SCORE = -10.0`（敌方更多）、`AI_INSUFFICIENT_MAX_HP_SCORE = -10.0`（体力上限不足）。评分只影响是否确认，不改变演出内容、上限代价或每轮次数。
- 【咬它】（星与穹共用同一技能）是非欢愉技的回合开始前技能，AI 同时决定是否发动与目标：目标优先级为“手牌数 `≥ AI_ALLY_MANY_CARDS_THRESHOLD = 8` 的队友（`8.0`）→ 有欢愉技的队友（`6.0`）→ 手牌数 `≥ AI_ALLY_SOME_CARDS_THRESHOLD = 5` 的队友（`4.0`）→ 自己（`2.0`）”，敌方目标固定 `AI_TARGET_HOSTILE_PRIORITY = -6.0`、非法目标 `AI_TARGET_INVALID_SCORE = -20.0`；只要最高优先级目标**不是自己**就无条件发动，最高优先级是**自己**时仅当可弃置花色中牌价值最低者 `≤ AI_SELF_TARGET_MAX_COST_VALUE = 2.0`（牌价值按 `AI_COST_VALUE_WEIGHT = 0.5` 折算）才发动。评分只影响是否发动与目标选择，不改变花色**整局**额度、分流口径或额外阶段。
- 【好活】是欢愉技，只在阿哈时刻演出时评估弃置目标，且两步选择（先选角色、再选该角色场上的一张牌）**共用同一套单牌收益口径**：第一步按该角色场上牌里收益最高的一张给该角色打分，第二步按实际所选牌打分，从而避免选出“角色本身不错、但实际没有好牌可弃”的目标。单牌档位为：我方角色判定区的延时锦囊按 `AI_ALLY_JUDGMENT_VALUE = 9.0` 计，敌方装备区的牌按 `AI_HOSTILE_EQUIPMENT_VALUE = 6.0` 计，其余场上牌按 `AI_DEFAULT_FIELD_CARD_VALUE = 1.0` 计，非法选人或非法选牌返回 `AI_INVALID_CARD_SCORE = -20.0`；友方判定阈值为 `AI_ALLY_ATTITUDE_THRESHOLD = 0.0`。第一步从权威快照读取公开的装备区与判定区（已废除栏位与已废除判定区跳过，与核心候选口径一致），第二步读取请求自带的候选集合。延时锦囊通过卡牌定义的 `type == "trick"` 且 `delayed == true`（辅助接口 `is_delayed_trick_definition()`）识别，**不硬编码牌名**。评分只影响选择，不改变「场上」范围、候选顺序或弃置数量。
- 【当赏】是欢愉技，只在阿哈时刻演出时评估目标：友方基础分 `AI_ALLY_BASE_SCORE = 4.0` + `AI_ATTITUDE_WEIGHT = 0.5 × 敌我态度` + `AI_LOW_HAND_COUNT_WEIGHT = 0.3 ×` 低手牌倾向（手牌越少得分越高）；敌方目标固定 `AI_HOSTILE_TARGET_SCORE = -6.0`、非法目标 `AI_INVALID_TARGET_SCORE = -20.0`。评分只影响目标选择，不改变摸牌张数。
- 【堪杀】的①②从手牌与装备中选择当前要求颜色且保留价值最低的牌，将支付低价牌以推进至③的战术收益一并评估；③对每名其他角色生成 `1` 点伤害动作，优先选择敌方。三节动作仍分别受同一出牌阶段的每节 `1` 次权威限制。
- 【征服】的改写入口是 `modify_ai_lethal_damage_consequence()`：只有行动者是刻律德菈本人、并且目标已公开为“翁法罗斯”势力时才生效，因此该领袖技在非领袖身份下完全不会参与估值。它先撤销通用层已计入的“主公误杀忠臣”惩罚 `12.0 + 2.0×(手牌数+装备数)`（仅当目标被感知为忠臣时才有这一项），再加回规则改写带来的 `4.0`（`4 × CARD_RESOURCE_VALUE`，对应摸四张牌）；最后在目标同时属于自己视角下的同阵营、体力不大于 `1`、手牌数为 `0` 时，按 `min(座次距离 ÷ 3, 1.0) × 8.0` 补回同阵营减员的战术损失。因此 AI 愿意用“1血0牌且行动靠后”的己方翁法罗斯角色换四张牌（同一局面由 `-24.0` 变为 `+4.0`），但不会为四张牌牺牲仍有体力或手牌的队友（同类 4 血 2 牌角色仍为 `-4.0`）；目标武将未公开时不进入改写，保持通用估值。
- 【泛音】的主动段为当前轮回节中每一张对应花色牌各生成一个动作，按“优先弃置自己没用的牌来触发效果”评分：牌价值越低，相对收益越高。锁定后段的黑色目标为每名仍有手牌的合法角色（含自己与队友）生成选择评分，敌方为正收益、友方为负收益，因此黑牌优先用于削减敌方手牌；当全场其他角色都没有手牌、只能由自己弃牌时，选牌评分优先交出红桃或方块，因为该牌被弃置后仍会通过红色效果摸回 `1` 张。主动段与两段选牌评分都只读取权威快照与选择请求上下文，评分实例没有运行时宿主，不得调用 `host`。
- 【回涛】把手牌 `+1` 的收益者固定记为事件中的轮回技持有者，并按统一资源换算评分：对自己与友方为正收益、对敌方为负收益，符合“对自己和队友无脑发动”的设计要求。是否发动由海瑟音本人决定，因此确认请求走 `request_card_selection`，不经过 `request_card_selection_for_player`。
- 【逐虚】的两个轮回节都是“随机指定、不询问目标”，因此 AI 只需回答“是否发动”。评分遍历权威快照中的全部角色：对敌方计价为正；随机范围若包含队友或自己，则按 `(1 + 该角色体力缺口) × 2.0` 叠加惩罚，用于表达“队友或自己体力值低的时候降低释放轮回②的收益”。动作评分下限固定为 `0.5`，保证存在合法动作时不会因为全员为友而彻底放弃发动。
- 【揭质】的估值入口是 `score_ai_choice`：节编号与目标直接取自选择请求上下文（而非武将私有数据），对敌方重复时为正收益并额外加 `1.0`，因此 AI 会把两次额度留到“对敌人释放轮回②”之后使用。目标为持有者本人时，在重复效果自身评分之上再叠加“重置自身全部技能”的收益：固定基础 `1.0` 分，加上每项已发动限定技 `3.0` 分（与【留白】同一可观测口径，重置本身不产生失去技能的代价）。
- 【留白】按“可复原的已发动限定技数量”计价，每项 `+3.0`；每仍持有一项轮回技扣 `1.0`，永久失去全部技能的基础代价为 `1.0`。由于已发动限定技与轮回技都只在权威快照的公开字段中出现，AI 无需访问运行时技能表即可判断“本回合限次技能与限定技是否已经用完”，符合“把收益最大化放在最后、但代价也很清楚”的设计口径。

- 【解构】的选牌口径为“无脑重铸未被记录的普通锦囊”：确认动作一律确认，不做价值权衡，价值判断只用于“是否发动”。发动判定要求手中存在**尚未被记录、且不是【无懈可击】**的可重铸锦囊，此时评分 `51.0（= 优先分 50.0 + 基础收益 1.0）`，记录容器为空时 `53.0（再叠加首次记录加成 2.0）`，否则返回 `0` 不发动。**优先分 50.0 用于落实“先重铸、再出牌”的出牌口径**：通用用牌评分由 `player_result + 出牌顺序 × 0.12 - 牌面价值 × 0.08 + 逐目标收益` 组成，量级不超过十分，因此只要手中仍有尚未记录的锦囊，AI 一定先完成一次重铸，而不是把锦囊直接打出去（该分值不会造成死循环：每次重铸都真实消耗一张锦囊并记录牌名，手中没有符合条件的锦囊时评分立即回到 `0`）——【无懈可击】虽然可以被重铸，但它不会被记入容器、也不解锁【灵感】，为它消耗一次出牌动作属于纯亏。选牌确认分按候选档位排列：未记录的可记录锦囊 `110.0（= 100.0 + 10.0）`、已记录的可记录锦囊 `100.0`、【无懈可击】等不可记录锦囊 `5.0`。三个档位都远高于任何单张手牌的保留价值，原因是通用选牌评分把被选中的手牌按 `-牌面价值` 计入费用、而取消动作恒为 `0` 分：旧口径 `基础收益 1.0 - 被重铸牌保留价值` 对【南蛮入侵】这类高面值锦囊仍为负数，AI 于是持续选择取消；由于本技能没有次数上限、取消既不消耗次数也不移动任何牌，AI 会在同一出牌阶段反复“发动→取消”，直到触发 `max_ai_actions_per_turn = 64` 被强制结束出牌阶段，表现为“AI 把自己的回合作废”。AI 没有运行时宿主，因此牌面定义只能从选择请求候选的 `card_data.definition_id` 读取，已记录牌名只能从权威快照中该玩家的 `recorded_card_names` 公开字段读取，不得访问控制器或玩家状态。
- 【灵感】的估值先遍历“效果牌名 × 目标牌名”的全部组合（含“不使用二段”的单段方案），再让四步选择指向**同一个组合**，从而保证“选中什么”与“能否结算”完全一致。组合收益 = 效果牌名自身的 `ai.value`（数组型 `value` 统一取首项：数组语义是“按同名牌数量递减”，而【灵感】是视为使用、不消耗手牌，没有同名牌张数这一上下文；取值前必须显式判型，空数组与非数值配置回退 `1.0`），叠加目标上限变化量与“群体接受者收益”。**基准必须是效果牌名而不是目标牌名**：实际结算的效果始终由效果牌名决定，目标牌名只提供目标规则，只有共用同一基准，“单段”与“二段”才可比；否则一张高价值目标牌名（【无中生有】的 `value` 为 `9.2`）会让任何二段组合凭空胜出，AI 就会把【南蛮入侵】的效果配上【无中生有】的目标规则送给所有角色。目标上限变化量按**效果自身的目标方向**分档：对目标不利的效果（`ai.target_result < 0`，伤害、横置、拆牌、牵牌、跳阶段）上限提高 `+1.5`、上限降低 `-1.0`——【铁索连环】的价值恰恰在于一次横置两名敌人，把它换成单目标牌名的目标规则等于削弱这次结算；对目标有利的效果（`target_result > 0`，增益、回复）上限提高不加分（多覆盖的目标里可能包含对手）、上限降低 `+1.0`（拆成单体以避免把增益送给敌人）。**目标规模收益**再按“实际能多覆盖几名角色”线性叠加，同样只作用于不利效果：`_count_coverable_targets_for_ai` 统计每套规则真正能覆盖的角色数——自动展开的群体模式按实际存活角色数计（不是配置上限 `99`），显式目标模式取“配置上限”与“当前候选数”的较小值，自指模式固定为 `1`；规模增量中超出第一个目标的部分每多一人 `+1.0`（首个目标的规模变化已由上限变化量计价，两层相加不重复）。因此【顺手牵羊】的效果配【铁索连环】的目标规则（`1 → 2` 人，`9.0 + 1.5 = 10.5`）与配【南蛮入侵】的目标规则（4 人局 `1 → 3` 人，`9.0 + 1.5 + 1.0 = 11.5`）都严格高于它自己的单段 `9.0`，且覆盖所有其他角色时收益最高——**获得队友的牌不构成负收益**（牌进入使用者手中，队伍总资源不减少），对手越多能牵到的牌越多，因此牵牌、拆牌、火攻这类效果的目标规模必须单调递增计价。**群体接受者收益**只作用于“不询问目标、自动展开”的 `all_others` 与 `all_players`：对增益效果逐角色累加 `target_result × 敌我态度 × 2.0`（`all_others` 排除使用者自身），队友多时为正、对手多时为负；对不利效果不作修正，其目标数量已由上限变化量体现。**不可结算的组合在评分阶段就被排除**，判定条件与权威目标枚举对齐：①次数额度未用尽——按 `play_limit`、`play_limit_scope`、`play_limit_group` 与次数豁免历史复算，技能与武器提供的次数加成不计入，宁可少发动也不选中已用尽的组合；②目标模式展开条件成立——`self` 恒成立、`self_wounded` 要求自己已受伤、`all_players` 恒成立、`all_others` 至少存在一名其他存活角色；③显式目标模式的候选数不小于 `min_targets`——候选按存活未离场、`single_other_with_cards` 区域非空、`single_with_hand` 有手牌、`weapon_holder` 有武器、`wounded` 已受伤过滤；④满足 `distance_limit`——`one` 要求距离不超过 `1`，`attack_range` 要求距离不超过攻击范围，其中距离与攻击范围分别读取 `NonameAIEvaluator.get_distance` 与 `get_attack_range`。四步评分依次为：①选效果牌名 `100.0 + 该牌名的最优组合收益 + 可选目标牌名数量 × 0.1`（该牌名没有任何可结算组合时返回 `0`，即不确认）；②确认重定向只在**二段严格优于单段**时给 `100.0`，否则给 `-5.0`——通用评分给“已确认但无牌无目标”的动作有一条 `+0.1` 的兜底分，而“取消”动作恒为 `0.0`，因此只有负分才能让取消真正胜出，落实“二段只在严格更优时才启用、否则只用一种牌名结算”这一原文允许的用法；③选目标模式牌名 `100.0 + 该组合收益`（组合不可结算时返回 `0`）；④目标选择确认 `100.0 + 逐目标收益`，逐目标收益 = `效果目标方向 × 敌我态度 × 2.0`（态度对友方为正、对敌方为负），于是【铁索连环】这类不利效果在敌人身上得正分、在自己或队友身上得负分，且“两名敌人”高于“一名敌人”；通用选择评分在该分支只读取首个目标的态度、且不乘效果方向，其 `态度 / 5.0` 的加分足以盖过真实差异（对自己约 `+2.0`、对敌人约 `-0.8`），因此必须由技能用放大后的权重覆盖——权重 `2.0` 使一名敌人贡献 `+4.0`、使用者自己贡献 `-10.0`。发动判定同样先做可结算性预筛：存在至少一个可结算组合时返回 `2.0`，否则返回 `0`。四步的保底分 `100.0` 远高于任何牌面收益，因此“是否确认”只受组合优劣影响，不受通用策略的手牌费用评分影响——这一步是防止“发动→取消”空转的关键，因为取消既不消耗阶段次数也不移除记录。四步评分同样只读权威快照与请求上下文。
- 【看破】的确认评分按锦囊性质分档：对【南蛮入侵】【万箭齐发】【决斗】【过河拆桥】【顺手牵羊】【火攻】【铁索连环】【水淹七军】【乐不思蜀】【兵粮寸断】【闪电】等不利锦囊固定 `+2.0`；对【桃园结义】【五谷丰登】【无中生有】等有利锦囊固定 `-3.0`；其余锦囊保守地按不利处理。该设计落实“几乎可以无脑使用，除非是五谷丰登、桃园结义这类正向锦囊”。
- 【鉴映】的关键约束是**主动动作评分与材料步确认评分必须由同一个毛收益函数驱动**。毛收益分三档：①自己在护盾不低于 `1` 且手牌最高最低保留价值差达到 `2.0` 时为自身升级 `3.0`（低价值 A 换高价值 B，收益确定）；②否则场上存在**有护盾且有手牌**的敌对角色时为对敌发动 `1.2`（从对方不可见手牌中博取收益）；③两者都不成立时才是友方目标 `0.2`。主动动作分 = 毛收益 − 最低手牌价值 `× 0.3`，材料步确认分 = 毛收益 − 所选牌保留价值 `× 0.3`，两处同式同参，因此“动作层愿意发动”时**最低价值材料必然取得正分**；材料候选之间的排序也完全由所选牌价值决定，低价值牌优先。目标步只在①成立时给自己记 `3.0`，否则给自己记固定 `-3.0`，从而让敌人（`1.2`）或队友（`0.2`）胜出——自己无护盾、或手牌没有价值差时，自选只会公开自己的手牌却换不到更高价值的牌。B 来源步禁止选择 A 本体（违规 `-6.0`）；来源是他人时牌面不可见，按均等处理。**若材料步采用“只返回 −所选牌价值”的口径，最低价值牌也常常为负分，而取消动作恒为 `0` 分，AI 会被判为取消更优，于是在同一出牌阶段内无限重复“发动→取消”**——该技能每阶段限一次但取消不消耗次数，因此循环不会自行收敛，表现为 AI 在自己回合卡死（与【解构】旧口径的死循环同源，区别是【解构】无次数上限、最终被 `max_ai_actions_per_turn` 截断，而【鉴映】会一直停在同一步）。

- 【奇袭】是强制触发，不生成选择动作，AI 也不会为它构造任何目标或费用。军功达到 `6` 时【奇袭】不再增加军功，而是移除 `5` 枚并保留剩余（阈值 `6` 大于移除量 `5`，因此该分支自身不会把军功清零，`6 - 5 = 1`）；军功被【升变】“移除场上所有的军功”整体清空时，持有者才失去该技能；随后按原技能类型复原其出牌阶段额度或推进其轮回节，因此 AI 侧没有需要预估的“第二次结算”价值；触发器技能的两类判定也不需要 AI 参与，规则层直接读技能源码的轮回技标签与“出牌阶段限一次”正文声明。
- 【负火】和【轮回】均是锁定/觉醒触发，不交给AI取消。通用AI从公开火种数与觉醒后形态读取可见局势，不猜测形态私有状态中的友方ID。
- 【薪继】不生成主动动作，唯一估值入口是 `score_ai_choice()`：是否发动由受伤角色自己决定，因此它读取受伤角色对白厄的态度——态度大于 `0.0` 时固定返回 `+1.0` 并确认，否则返回 `-0.1`。该负值恰好抵消通用零材料确认请求的 `0.1` 兜底分，使最终分为 `0.0`、取消动作胜出，落实“队友无脑发动、敌人不发动”。评分不读取或猜测隐藏信息：势力与“本局首次”两个条件已由规则层按公开事实过滤，AI 只负责回答是否发动。
- 【天裁】为②枚举不超过 `X` 名的合法【火攻】目标组合，为③枚举单一目标并按 `X-1` 张【火攻】累计收益；①以无伤害来源的 `X` 点火焰自伤作为风险。AI比较三节当前可用动作，不会跳过轮回节直接选攻击效果。①在自伤点数不小于持有者当前体力时额外扣除 `30.0` 的否决级惩罚，避免AI以濒死返生为代价推进轮回；②与③没有任何合法火攻目标时不生成动作，空节推进交由人工玩家按需触发。
- 【弑魂】①枚举其他角色的有序组合，对敌方被令攻击卡厄斯兰那的风险扣分，对友方能产生的用牌/伤害联动收益加分；②仅对上次保存且当前仍合法的原目标生成火【杀】动作，逐目标忽略已经阵亡、离场或被目标技能限制挡下的角色，其余目标照常参与普通【杀】的响应、防具、伤害与友敌评分。②与①共用同一批目标，其覆写忽略本阶段【杀】次数与到目标距离，因此【永劫】状态下持有者用尽【杀】基础次数、或①指定了超出持有者攻击范围的角色时，AI仍然能得到这条可执行的反击动作；AI评分本身不读取次数与距离，无需为这两项覆写增加分支。一次发动的连续火【杀】由统一结算队列自动排空，中途不向AI重新开放普通出牌选择。由于【永劫】已把持有者手牌持续视为火【杀】，①产生的火【杀】无法被【闪】响应，因此所选使用者数量不小于当前体力时额外扣除 `30.0` 的否决级惩罚；①没有可指定角色、或②的原目标全部失效时，②只生成一条空目标动作，并由评分端的空目标否决决定是否放弃。
- 【永劫】不生成 `use_skill` 动作。锁定效果已把普通手牌区内全部 `ai.damage=false` 的牌持续改为火【杀】逻辑定义，基础AI直接把它们当作带无距离标记的标准火【杀】枚举和评分，不能选择原牌效果；新获得的非伤害手牌在 `gainAfter` 后立即进入同一状态。永劫进入/退出和濒死返形均为强制结算，不创建AI选项。
- 【同袍】是轮回技，AI 按四节方向性收益评分，并为“空过推进”保留小正分：①自伤仅在自身体力大于 `AI_SELF_DAMAGE_MIN_HP = 2` 且存在体力不大于 `AI_LOW_HP_THRESHOLD = 2` 的队友时给正分（自伤的目的是用护盾救队友）；②护盾对队友按 `态度/5.0` 方向计分；③④弃牌按“该牌保留价值 × 区域权重”计价——判定区 `AI_ZONE_WEIGHT_JUDGMENT = 1.6`（拆除延时锦囊价值最高）、装备区 `AI_ZONE_WEIGHT_EQUIPMENT = 1.1`、手牌区 `AI_ZONE_WEIGHT_HAND = 0.7`，队友判定区存在延时锦囊时额外 `+AI_ALLY_JUDGMENT_RESCUE_VALUE = 1.5`；空过推进统一记 `AI_SECTION_ADVANCE_VALUE = 1.2`，完全无内容时记 `AI_EMPTY_SECTION_VALUE = 0.5`。以上权重只影响决策。**评分只许读快照**：AI 评分实例由 `bind(null, player_id)` 建立（`host == null`），因此①节号取自动作负载的 `payload.reincarnation_section`（枚举时写入，不读运行时 `get_reincarnation_section_index()`，后者在只读实例上恒为 `0`，会把②③④全部按①定价）；②`_has_judgment_card` / `_resolve_card_zone` 从快照的 `judgment_area` 与 `equipment` 读区域（两者均为公开信息），对手暗手牌自然落回 `hand`；③④第二步的选牌请求声明 `ai_choice_card_semantics = "discard_target"`，统一选择评分据此把选中牌判为收益而不是费用（该请求 `min_card_select = 1`，默认口径会按牌面价值取负，使AI对任何目标都取消）。三条口径缺一即会造成“AI提交④后无限取消、界面停在思考”的死循环。
- 【岳峙】按牌的收益方向分流：`ai.damage == true`（伤害类）走**挡伤分支**，自身体力须大于 `AI_SELF_MIN_HP = 1`，收益为 `被救残血队友数 × HP_RESOURCE_VALUE × AI_BODYGUARD_RATIO = 0.9`，再减去自身 `AI_SELF_DAMAGE_TAKEN = 1` 点伤害代价，没有残血队友时返回 `0`；`ai.beneficial == true`（正收益类）走**剥夺分支**，仅当原目标中敌方人数严格多于我方时发动，收益为 `(敌方人数 + 结算次数 X) × AI_BENEFICIAL_RATIO = 0.8`；其余牌返回 `0`。
- 【断界】首次发动（列表仍含④）时给④额外 `AI_LAST_CHANCE_BONUS = 1.0` 加成，因为④位于列表末尾、第一次发动后即被删除，是唯一的使用窗口。方向性评分统一为 `±态度/5.0 × 权重`：干扰方向（①横置敌人、④把敌人翻至背面）取 `AI_DISRUPT_VALUE = 1.6`，协助方向（②竖置队友、③把队友翻回正面）取 `AI_ASSIST_VALUE = 1.2`，因此对敌人发动协助项或对队友发动干扰项自然得到负分；某选项在权威快照中没有任何合法目标时返回 `-100.0`。技能描述里用来划掉已删除选项的删除线（含 `SkillDescriptionView` 为被划片段使用的主题 `danger` 醒目色）只影响显示，不进入 AI 的任何评分输入。
- 【遥击】是锁定技，不生成技能动作；“能打到最远敌人”由合法动作枚举自动获得（枚举与界面、提交共用同一处距离校验）。补充评分在 `modify_ai_card_action_score()` 中：只对使用【杀】且**唯一目标**恰好是最远角色、且该目标态度为负的动作追加 `AI_FARTHEST_REACHABILITY_BONUS = 1.5`，对队友使用【杀】不追加收益。
- 【凌霜】按 `AI_BLIND_DISCARD_HAND_THRESHOLD = 2` 实现“对手牌数不小于2的敌人目标无脑发动”，直接返回 `100.0`；持有者已是背面时本次只会翻回正面，属于解除自身翻面，返回 `AI_UNFLIP_VALUE = 1.0`；持有者体力不大于 `AI_CRITICAL_HP_THRESHOLD = 1` 时被翻面会跳过下一个完整回合而无法自救，返回 `-100.0`；其余情形按 `min(2, 目标手牌数) × CARD_RESOURCE_VALUE + AI_FREE_SLASH_VALUE = 1.0 − AI_TURN_OVER_COST = 2.2` 评分，只有收益严格大于翻面代价才发动。
- 【悬壶】是锁定技，AI 不注册任何评分钩子：该技能没有主动入口、没有可取消窗口，手牌上限豁免与死亡后摸【桃】都由规则层自动完成，任何评分都无法改变其触发与否。该技能也不参与 AI 的手牌上限推算——通用估算读到的 `PlayerState.get_hand_limit()` 与基线一致，只是弃牌阶段的溢出张数会先扣除【桃】。
- 【生息】唯一的 AI 入口是 `score_ai_choice()`，回答“摸一张牌”还是“令本回合结束后X+1”：当前累计 `X` **大于**持有者手牌数时，“摸一张牌”取统一单牌资源值 `NonameAIEvaluator.CARD_RESOURCE_VALUE`、“令本回合结束后X+1”取 `0.0`；`X` **不大于**手牌数时反过来给累加项 `AI_INCREASE_PREFER_HAND_DIVISOR = 1.0 × 0.5 × CARD_RESOURCE_VALUE`、摸牌项取 `0.0`。两个分支的取值恒不相等，因此不会退化成 `0` 分平局；该评分只影响二选一的方向，不改变 `X` 的累加时机（**使用基本牌时所在的那个回合**结束的 `phaseAfter`，含他人回合里打出的【闪】等，按回合角色分桶结算）、每回合额度刷新口径或摸牌张数。
- 【万死】唯一的 AI 入口是 `score_ai_choice()`，回答“是否确认发动”：持有者快照体力**仍恰为 `1`** 时确认项固定取 `AI_CONFIRM_VALUE = 1.0`（等价于一张牌的通用资源值），等待期间体力已经变化时改为 `-100.0` 否决，取消恒为 `0.0`。评分只影响是否登记，不改变主演顶替规则、每回合 `1` 次的记账口径（按全局回合号）或额外回合数量；登记后真正的两段效果（成为主演、执行额外回合）在 `phaseAfter` 由规则层无条件完成，AI 不再有机会干预；该时机订阅 `role="global"` 并按“登记的回合角色 + 登记的回合号”双重匹配，因此对手回合内受伤的登记同样会在**对手回合**结束时兑现。
- 【支离】的评分入口是 `modify_ai_card_action_score()`，口径是“按**改写后实际命中的人**重算，而不是按想打谁就指定谁”：先调用通用层同一套【杀】目标评估求出**原目标**的分数并从总分中减去，再对改写后的**每个座次相邻角色**逐个复用同一份牌效评估累加（相邻集合包含持有者自己或队友时自然得到负分），最后叠加持有者失去 `1` 点体力的统一资源代价 `HP_RESOURCE_VALUE`。没有任何合法相邻角色时保留原目标，因此只扣体力代价、不重算目标收益。相邻**集合**由技能内部的快照版本 `_get_snapshot_seat_neighbor_ids()` 计算，与规则层 `GameState.get_seat_neighbor_player_ids()` 使用**完全相同**的算法（座次上取“下家 + 上家”、跳过离场、存活不足三名时去重），因此规则层与 AI 层不会给出不同答案；规则层随后会按“从持有者开始的行动顺序”重排该集合以决定结算次序（`_get_seat_neighbor_ids()` 统一走 `_sort_by_action_order()`，使预览与结算同序），AI 侧对每个邻居逐个累加、与顺序无关，因此不重排也不影响评分；该函数只读取权威快照的 `player_id/alive/out_of_game` 公开字段，不访问运行时宿主。锁定技的第①②段（自身目标合法性、主演用【杀】造成伤害时回复）是规则层自动生效的修正，AI 通过合法动作枚举与通用【杀】收益自然获得，不需要额外评分——唯一需要补充的是第①段带来的“可以用【杀】打自己”这一新动作：此时相邻集合会包含持有者本人，扣分项使其通常为负，因此 AI 不会无故自伤。
