# 崩铁杀

《崩铁杀》是使用 Godot 4.6 与 GDScript 开发的标准身份制同人桌游框架。项目以本地“三国杀官方规则集 3.0”网页快照作为规则依据，以本地无名杀资源作为架构、数据组织、AI 与通信分层参考，不实现国战玩法。

当前工程已提供可运行的四人身份局演示桌面，并支持调整为 2 至 10 人。对局核心、AI、网络、数据与 UI 相互分层；人类玩家、内置 AI 和未来联机客户端统一通过 `PlayerAction` 下发操作。

## 运行方式

1. 使用 Godot 4.6.3 或兼容的 Godot 4.6 版本打开 `project.godot`。
2. 运行主场景 `res://scenes/main.tscn`。
3. 默认本地玩家为座次 0，其余玩家由基础 AI 控制。
4. 点击卡牌、点击青色合法目标、点击“确定使用”完成出牌；也可把卡牌拖到合法角色后确认使用。
5. 顶栏“牌名”按钮可在《崩铁杀》自定义名与原版三国杀牌名之间全局切换。

## 自动校验

运行 `res://tests/smoke_test.tscn` 可执行数据规模、双名称、效果映射、身份人数和纯 AI 对局烟雾测试。测试使用固定随机种子，不依赖图形界面。
