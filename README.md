# 崩铁杀

《崩铁杀》是使用 Godot 4.6 与 GDScript 开发的标准身份制同人桌游框架。项目以本地“三国杀官方规则集 3.0”网页快照作为规则依据，以本地无名杀资源作为架构、数据组织、AI 与通信分层参考，不实现国战玩法。

当前工程已提供可运行的八人身份局演示桌面，并可在右上菜单把下一局调整为2至10人。开局由主公先从默认5张候选中选将并亮出，随后其他玩家同时选择并同时亮出。对局核心、AI、网络、数据与 UI 相互分层；人类玩家、内置 AI 和未来联机客户端统一通过 `PlayerAction` 下发操作。

卡牌与武将牌都以 `Node2D` 为正式牌面根节点，输入由透明子组件处理。卡牌使用动画直接复用同一108×148像素正式牌面进入中央弃牌展示区，不创建简化替代牌。

## 运行方式

1. 使用 Godot 4.6.3 或兼容的 Godot 4.6 版本打开 `project.godot`。
2. 运行主场景 `res://scenes/main.tscn`。
3. 默认本地玩家为座次0，其余玩家由基础 AI 控制；按选将界面提示选择并确认武将。
4. 点击卡牌、点击青色合法目标、点击“确定”完成出牌；也可把卡牌拖到合法角色后确认使用。
5. 右上“菜单”可切换《崩铁杀》/三国杀牌名、设置下一局人数并重新开局。
6. `Enter` 确认、`Esc` 或鼠标右键取消；未选牌时按 `Space` 可结束出牌阶段。

## 自动校验

运行 `res://tests/smoke_test.tscn` 可执行数据规模、双名称、效果映射、身份人数、Node2D牌面、分阶段选将、无名杀布局组件默认参数和纯 AI 对局烟雾测试。测试使用固定随机种子，不依赖图形界面。

运行 `res://tests/ui_layout_test.tscn` 可把正式界面缩放到1152×648客户区，并通过十人只读快照验证武将牌、全部座位、底部功能区和右上菜单按钮的边界、避让与鼠标命中。
