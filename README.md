# 崩铁杀

《崩铁杀》是使用 Godot 4.6 与 GDScript 开发的标准身份制同人桌游框架。项目以本地“三国杀官方规则集 3.0”网页快照作为规则依据，以本地无名杀资源作为架构、数据组织、AI 与通信分层参考，不实现国战玩法。

当前工程启动后先显示身份模式主菜单，默认可开始八人标准身份局，并可在设置中调整为2至10人。每局都重新随机分配全部身份与真人玩家映射；领袖先从默认5张候选中选将并亮出，随后其他玩家同时选择并同时亮出。对局核心、AI、网络、数据与 UI 相互分层；离线玩家、局域网客户端和内置 AI 统一通过 `PlayerAction` 下发操作，局域网由房主权威结算并按观察者裁剪私有快照。

卡牌与武将牌都以 `Node2D` 为正式牌面根节点，输入由透明子组件处理。当前标准身份局的卡牌使用流程由真实 `CardUseEvent` 子树驱动，逐目标响应可暂停并从原 `content` 恢复，处理区回收通过 `after` 队列完成。卡牌使用、展示与弃置动画复用同一111×148像素正式牌面，从实际来源进入中央展示队列，不创建简化替代牌；表现 ID、实体 UID、公开处理区 UID 快照和移动消费状态共同保证重复信号、缺失座位锚点或漏失最终移动通知不会生成或遗留异常中央牌面。

## 运行方式

1. 使用 Godot 4.6.3 或兼容的 Godot 4.6 版本打开 `project.godot`。
2. 运行主场景 `res://scenes/main.tscn`。
3. 单机游玩：需要调整名称、主题、速度或人数时先点击“设置”，再按“开始游戏”；这些游戏设置与下一局人数会保存到本地，重启后自动恢复。
4. 局域网游玩：先在顶部“联机设置”保存玩家名称与联机形象，再点击“局域网联机”。连接入口只读显示玩家名；房主可填写最长32字符的房间密码与端口后创建房间，客户端填写房主 IPv4、相同端口和密码加入。成功后进入独立联机大厅：玩家以带空位同规格边框的所选武将插画入座，可点击空位换位、在左下聊天，并由房主在右下调整身份模式、2至10人总人数和密码；至少2名真人后可开始，空位由 AI 补齐。默认端口为7000；关闭房间后可立即用同一端口重新创建。系统防火墙需允许游戏使用该 UDP 端口。
5. 标准身份局中领袖与真人玩家都可随机位于任意座次，两者不绑定；首回合由随机座次的领袖开始，其余空位由基础 AI 控制。按选将界面提示选择并确认武将。
6. 点击卡牌、点击青色合法目标、点击“确定”完成出牌；拖动手牌只调整本地同分区显示顺序。
7. 卡牌默认显示《崩铁杀》牌名；主菜单的“设置”和右上“菜单”均可切换《崩铁杀》/三国杀牌名、调整 UI 风格、游戏速度、AI 响应速度与游戏人数；左侧“记录”按钮可展开或收起完整对局日志。
8. `Enter` 确认、`Esc` 或鼠标右键取消；未选牌时按 `Space` 可结束出牌阶段。
9. Android 使用横屏运行：轻点卡牌或武将牌执行选择，拖动手牌调整同分区顺序，长按卡牌查看规则说明，长按武将牌查看详情；系统返回键按当前界面执行取消、返回或打开局内菜单。
10. Android 使用 Vulkan Mobile 渲染、固定横屏、60 FPS上限与VSync；该策略用于避免一加Ace 5等高刷新率Adreno设备在启动、旋转或前后台切换时出现整屏闪烁。
11. Android触摸可直接操作卡牌名称/UI风格下拉框、速度滑条、人数数字框、联机名称、房主IP、端口、密码及创建/加入按钮；联机设置不会在打开时自动弹出输入法。
12. Android进入联机大厅、连接成功、关闭文本设置或正式进入对局时会主动隐藏软键盘；聊天输入法只在玩家主动点击聊天框时出现。

## Android APK 导出

1. 在 Godot 编辑器设置中配置 Android SDK 路径，并安装与当前 Godot 版本匹配的 Android 导出模板。
2. 选择“项目 → 导出 → Android”，并在每次导出时自行选择 APK 文件名与保存位置。
3. 发布版本必须在编辑器中配置自己的 Release Keystore、别名和密码；仓库不保存签名密钥或密码。
4. 当前预设使用包名 `com.hsrkill.game`、最低 SDK 23、目标 SDK 35、ARM64-v8a，并声明局域网所需网络权限。
