# 崩铁杀

《崩铁杀》是使用 Godot 4.6 与 GDScript 开发的标准身份制同人桌游框架。项目以本地“三国杀官方规则集 3.0”网页快照作为规则依据，以本地无名杀资源作为架构、数据组织、AI 与通信分层参考，不实现国战玩法。

当前工程已提供可运行的八人身份局演示桌面，并可在右上菜单把下一局调整为2至10人。每局都重新随机分配全部身份与本地玩家座次；主公先从默认5张候选中选将并亮出，随后其他玩家同时选择并同时亮出。对局核心、AI、网络、数据与 UI 相互分层；人类玩家、内置 AI 和未来联机客户端统一通过 `PlayerAction` 下发操作。

卡牌与武将牌都以 `Node2D` 为正式牌面根节点，输入由透明子组件处理。当前标准身份局的卡牌使用流程由真实 `CardUseEvent` 子树驱动，逐目标响应可暂停并从原 `content` 恢复，处理区回收通过 `after` 队列完成。卡牌使用、展示与弃置动画复用同一111×148像素正式牌面，从实际来源进入中央展示队列，不创建简化替代牌；表现 ID、实体 UID 和移动消费状态共同保证重复信号不会生成第二张牌面。

## 运行方式

1. 使用 Godot 4.6.3 或兼容的 Godot 4.6 版本打开 `project.godot`。
2. 运行主场景 `res://scenes/main.tscn`。
3. 标准身份局中主公与本地玩家都可随机位于任意座次，两者不绑定；首回合由随机座次的主公开始，其余玩家由基础 AI 控制。按选将界面提示选择并确认武将。
4. 点击卡牌、点击青色合法目标、点击“确定”完成出牌；也可把卡牌拖到合法角色后确认使用。
5. 卡牌默认显示三国杀牌名；右上“菜单”可切换《崩铁杀》/三国杀牌名、设置下一局人数并重新开局，左侧“记录”按钮可展开或收起完整对局日志。
6. `Enter` 确认、`Esc` 或鼠标右键取消；未选牌时按 `Space` 可结束出牌阶段。

## 自动校验

运行 `res://tests/event_runtime_test.tscn` 可验证 `GameEvent` 父子事件、`next/after`、长期根事件不阻塞新子树、多通道暂停、`ChoiceRequest/ChoiceResponse` 旧响应拒绝、终止三态、触发排序、查询修正、虚拟牌、无懈交替和实体移牌知识；测试使用固定数据，不依赖图形界面。

运行 `res://tests/harvest_choice_test.tscn` 可验证活动出牌请求与五谷选择请求交错时仍使用全局唯一请求 ID，本地玩家提交展示牌后能够继续后续目标、收尾原锦囊并恢复出牌阶段。测试使用固定两人局与延迟模拟点击，不依赖图形界面。

运行 `res://tests/response_choice_test.tscn` 可验证 AI 使用【杀】后，本地玩家提交【闪】能够消费响应牌、收尾原【杀】、恢复 AI 出牌阶段并重新安排唯一后续任务。

运行 `res://tests/gameplay_regression_test.tscn` 可验证真实 `CardUseEvent` 父子关系、五组使用时机、四组动态逐目标时机、`excluded/directHit/customArgs` 上下文、响应选择归属、唯一 `contentAfter`、`orderingDiscard/cardsDiscard` after 回收，以及无懈、群体牌、濒死和装备选择恢复。

运行 `res://tests/inline_hand_choice_test.tscn` 可验证本人手牌响应与弃牌直接使用底部确定/取消按钮、本地装备候选右移并直接选择、装备空槽固定位置、宝物动态第五行、普通出牌逐牌合法性、非候选牌深灰禁用、多选数量约束，以及五谷展示牌仍使用独立窗口。

运行 `res://tests/phase_progression_test.tscn` 可验证兵粮寸断跳过摸牌、乐不思蜀跳过出牌、翻面跳回合和濒死救援取消经过异步选择后都能恢复到唯一后续阶段，并且同一救援轮不会重复询问已经取消的角色。

运行 `res://tests/smoke_test.tscn` 可执行162张牌堆、双名称、效果映射、随机身份与座次、主公首回合、体力人数阈值、响应顺序、终局结算停止、判定死亡转交、银月枪、统一卡牌场景、武将状态覆盖、判定菱形、体力扣减方向、全宽装备条、手牌悬停顶置、滑条阈值、摸牌数量堆叠动画、动画中途重开清理、分阶段选将和纯 AI 对局烟雾测试。测试使用固定随机种子，不依赖图形界面。
