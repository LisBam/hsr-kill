# 崩铁杀

《崩铁杀》是使用 Godot 4.6 与 GDScript 开发的标准身份制同人桌游框架。项目以本地“三国杀官方规则集 3.0”网页快照作为规则依据，以本地无名杀资源作为架构、数据组织、AI 与通信分层参考，不实现国战玩法。

当前工程启动后先显示身份模式主菜单，默认可开始八人标准身份局，并可在设置中调整为2至10人。每局都重新随机分配全部身份与真人玩家映射；领袖先从默认5张普通随机候选及全部领袖技固定候选中选将并亮出，AI首任领袖会在本次全部合法候选中随机选择，随后其他玩家同时选择并同时亮出。开启全武将座次身份自选时，真人首任领袖在第一次面板一次确认武将、座次和身份，确认后不再进入其他玩家选将流程；AI首任领袖只先亮将，真人完成后优先补选一号位与领袖身份，只有该名额已被真人选择时才按剩余名额确认。房主可把普通随机候选设为1至20张，并为每人配置0、3、5、8、10或20张换将卡；车轮战改用独立的明置、暗置候选数量设置。对局核心、AI、网络、数据与 UI 相互分层；离线玩家、局域网客户端和内置 AI 统一通过 `PlayerAction` 下发操作，局域网由房主权威结算并按观察者裁剪私有快照。对局内置停滞自修复看门狗：检测到“无人可操作”的停滞时按软/硬两级自动修复（重排AI任务、清扫孤儿等待、托管无人认领座位），并以顶部横幅与对局日志提醒玩家；人类思考时间不受任何影响。

主菜单提供独立的2至10人“机缘大乱斗”。该模式继承身份模式的身份、胜负、死亡奖惩与选将规则，并挂载可插拔机缘组件：每轮各普通回合开始时按本轮在场人数倒数 `1/N` 使用相同概率检定，若整轮未触发则在轮末强制触发。触发后暂停玩法并让全体角色依次从本人私有的三张机缘卡中选择一张，全部选完后从当前回合角色开始逆时针结算。机缘卡无插画，只显示规则正文并使用绿、蓝、紫、橙、红五档品质色。

主菜单同时提供固定2人的“1v1车轮战”。该模式默认随机展示6名明置候选与4名暗置候选，后手按122221顺序先选；被选槽不消失并保持原有明暗状态，以带描边的深绿色“我方选择”或深红色“对方选择”标记归属。双方各从取得的5名武将中按顺序锁定3名出场武将；先手第一回合摸牌阶段少摸1张，前两名武将阵亡时清区、换将、补满体力并摸4张，第三名武将阵亡后对方获胜。暗置候选、本人五将和三将顺序均按观察者裁剪，不向对手快照泄漏。主菜单与局内菜单只显示当前模式适用的选将设置，车轮战两项候选设置范围均为3至20且合计至少10名。

主菜单另提供“过关斩将”：单人模式固定为1名本地玩家对1名AI（规则角色固定2名，菜单人数不可调整），局域网联机支持2至4名玩家协作对抗等量敌方AI，只有联机才可设置玩家数，座次按“玩家1、敌人1、玩家2、敌人2”交替行动，敌方每关的加强机缘由每名敌人共同获得。联机局新增“机缘选择”设置：投票选择（默认）让全体存活玩家同时从同一组三张候选中各投一票，全部提交后统一公开每名玩家所投机缘，票数最高者当选且人人获得，平票在同票中随机；各自选择则每名玩家独立三选一。玩家1固定红方先手；敌人逐名阵亡后保持退场，只有本层全部敌人阵亡才统一提升关卡、整组换上下一层武将并触发一次全体玩家机缘。联机局中阵亡且复活次数耗尽的玩家不会立即出局，只要仍有队友存活，进入下一关时便会以游戏初始状态复活（初始武将与技能、难度开局机缘、初始体力与起始手牌）并照常参与本关机缘选择；难度一至四通过开局机缘提供不同增益，难度一还拥有1次清区、回满并摸4张的复活，难度五保持无额外增益。该模式的“自选武将”只允许玩家从全部已登记武将中确认武将，不开放固定座次和红蓝阵营修改；敌方仍从独立的1至20张随机候选中自动选将。斗地主、机缘大乱斗与过关斩将的模式预览左上角提供“详情”入口，其他模式暂时隐藏。过关斩将支持局内“临时退出”存档：出牌询问空闲时点击右上菜单的“临时退出”立即保存并返回主菜单，操作结算进行中点击则在该操作结算完成后的最近空闲点自动生效；存档记录关卡、双方角色、全部牌区、回合与阶段进度和随机源。此后主菜单选中过关斩将时“开始游戏”变为“继续上次游戏”，点击即回到原出牌阶段或从下一回合继续，终局或重新开局会清除存档。

离线设置可开启“控制所有角色”。该开关在进行中的离线对局即时生效，只接管正式回合行动、响应与技能等规则操作；初次选将、车轮战抓将/阵容确认和手气卡仍由原真人与内置AI分别处理。关闭后立即恢复最初真人第一视角，把临时接管角色交还AI并重新安排当前AI选择或出牌动作；局域网模式隐藏并忽略该选项。第一视角判定区向右避让托管按钮，【八卦阵】独立发动询问默认预选防具但仍等待玩家确认。

主菜单顶部“所有卡牌”可在开局前浏览并搜索全部已登记武将牌、游戏牌与机缘牌。三类列表直接读取项目静态目录并复用正式牌面组件；武将牌与联机形象按指定势力顺序分组，游戏牌按基本牌、锦囊牌、装备牌及其子类顺序分组。点击武将牌后左侧显示正式牌面、右侧以黄色技能名列出完整技能，其他牌面继续显示完整规则说明；该页面不会创建对局、牌堆实体或机缘选择。

当前内容包含仙舟联盟武将停云（3体力，祥音/光覆），以及翁法罗斯武将万敌（5体力，血仇/弑神）、赛飞儿（3体力，聚寇/换日）、刻律德菈（3体力，升变/堪杀）、白厄（4体力，负火/轮回）、那刻夏（3体力，逐虚/揭质/留白）与大黑塔（3体力，解构/灵感/看破）；白厄觉醒后可显式替换为特殊武将卡卡厄斯兰那（5体力，天裁/弑魂/永劫）。通用轮回技状态机令轮回数从1开始，技能按①②等轮回节逐次推进，最后一节完成后回到①并增加轮回数；永劫可锁定当前节，也可由明确效果退出，技能复原可重置轮回、限定/觉醒与阶段次数。局内技能按钮、武将悬停/右键详情和局外“所有卡牌”会用高亮色显示当前轮回节、淡色显示其他节。普通随机选将统一排除 `special=true` 的特殊武将，仅允许特定规则显式生成。

区域废除支持武器、防具、进攻坐骑、防御坐骑和宝物五个装备栏独立设置；五栏全部废除才等价于废除整个装备区。废除装备栏或判定区会把区域内现有牌按标准离区流程置入弃牌堆，之后由用牌规则与最终移牌边界共同禁止新牌进入；恢复区域只恢复可用性，不返还旧牌。局内本地与其他玩家牌面会在原槽位显示不可交互的废除横条，废除判定区显示独立“废”菱形占位。

对局内提供聊天与本机回放：右上“菜单”按钮下方的“聊天”按钮可展开聊天窗口（单条最长200字符、历史最多100条，正文格式“玩家名：正文”，不显示时间），发送后发言者头顶显示停留4秒、按正文实际宽度收紧的聊天气泡；离线本地回环，局域网由房主权威署名并中继，客户端不能伪造发言人。对局全程自动录制本机视角快照与日志，战斗结束后的结算界面点击“保存回放”会弹出命名弹窗，可自定义回放名或留空按默认名保存为 `.lisbam_replay` 文件；主菜单“所有卡牌”右侧的“对局回放”内容页可浏览、重命名、顶置（顶置条目固定居顶）、按路径导出、导入与删除回放。点击“播放”会像进入一场新对局一样在正式牌桌上以录制端第一视角从头重演整局，直接复刻原对局表现流程：卡牌进入牌桌中心的使用/展示/判定飞牌、移牌与摸牌动画、技能发动提示与卡牌、技能的目标指示线一并重放；重演期间不可操作，只能以1×/2×/4×加速或退出回放，悬浮控制条可按住空白处拖动到任意位置避免遮挡画面；回放为纯本机文件不经网络传输。

卡牌与武将牌都以 `Node2D` 为正式牌面根节点，输入由透明子组件处理。当前标准身份局的卡牌使用流程由真实 `CardUseEvent` 子树驱动，逐目标响应可暂停并从原 `content` 恢复，处理区回收通过 `after` 队列完成。卡牌使用、展示与弃置动画复用同一111×148像素正式牌面，从实际来源进入中央展示队列，不创建简化替代牌；表现 ID、实体 UID、公开处理区 UID 快照和移动消费状态共同保证重复信号、缺失座位锚点或漏失最终移动通知不会生成或遗留异常中央牌面。

## 运行方式

1. 使用 Godot 4.6.3 或兼容的 Godot 4.6 版本打开 `project.godot`。
2. 运行主场景 `res://scenes/main.tscn`。
3. 单机游玩：需要调整名称、主题、速度或人数时先点击“设置”，再按“开始游戏”；这些游戏设置与下一局人数会保存到本地，重启后自动恢复。
4. 局域网游玩：先在顶部“联机设置”保存玩家名称与联机形象，再点击“局域网联机”。连接入口只读显示玩家名；房主可填写最长32字符的房间密码、端口与“自选身份”开关后创建房间，客户端填写房主 IPv4、相同端口和密码加入。成功后进入独立联机大厅：玩家以带空位同规格边框的所选武将插画入座，可点击空位换位、在左下聊天，并由房主在右下调整六种模式、对应合法人数、密码与“自选身份”；至少2名真人后可开始，空位由 AI 补齐。“自选身份”开启后每个位置右上角显示该位置绑定的身份徽记（身份局八人如一号位领袖、二三号忠臣、四号内奸、下排四位反贼；2v2上排两蓝下排两红；斗地主一号位地主等），玩家通过换位自选身份，开局按位置固定分配、不再随机洗牌；过关斩将无位置身份，该开关禁用。1v1车轮战大厅固定只显示2个位置，两名玩家1v1、各自选将。过关斩将房间的人数表示玩家数（2至4），每名玩家对应一名敌方AI。对局中意外掉线的客户端会自动重连并恢复原座位，期间由 AI 临时托管。默认端口为7000；关闭房间后可立即用同一端口重新创建。系统防火墙需允许游戏使用该 UDP 端口。
5. 内容浏览：点击顶部“所有卡牌”，再选择“所有武将牌”“所有游戏牌”或“所有机缘牌”；可输入名称、类别、品质、技能或说明关键词搜索，点击牌面查看完整资料。
6. 标准身份局中领袖与真人玩家都可随机位于任意座次，两者不绑定；首回合由随机座次的领袖开始，其余空位由基础 AI 控制。按选将界面提示选择并确认武将。
7. 点击卡牌、点击青色合法目标、点击“确定”完成出牌；拖动手牌只调整本地同分区显示顺序。
8. 卡牌默认显示《崩铁杀》牌名；主菜单的“设置”和右上“菜单”均可切换《崩铁杀》/三国杀牌名，在“崩铁风格”“暖木家园”“高级黑金”之间调整 UI 风格，并设置游戏速度、AI 响应速度与游戏人数；左侧“记录”按钮可展开或收起完整对局日志。
9. `Enter` 确认、`Esc` 或鼠标右键取消；未选牌时按 `Space` 可结束出牌阶段。
10. Android 使用横屏运行：轻点卡牌或武将牌执行选择，拖动手牌调整同分区显示顺序，长按卡牌查看规则说明，长按武将牌查看详情；系统返回键按当前界面执行取消、返回或打开局内菜单。
11. Android 使用 Vulkan Mobile 渲染、固定横屏、60 FPS上限与VSync；该策略用于避免一加Ace 5等高刷新率Adreno设备在启动、旋转或前后台切换时出现整屏闪烁。
12. Android触摸可直接操作卡牌名称/UI风格下拉框、速度滑条、人数数字框、联机名称、房主IP、端口、密码及创建/加入按钮；联机设置不会在打开时自动弹出输入法。
13. Android进入联机大厅、连接成功、关闭文本设置或正式进入对局时会主动隐藏软键盘；聊天输入法只在玩家主动点击聊天框时出现。

## Android APK 导出

1. 在 Godot 编辑器设置中配置 Android SDK 路径，并安装与当前 Godot 版本匹配的 Android 导出模板。
2. 选择“项目 → 导出 → Android”，并在每次导出时自行选择 APK 文件名与保存位置。
3. 发布版本必须在编辑器中配置自己的 Release Keystore、别名和密码；仓库不保存签名密钥或密码。
4. 当前预设使用包名 `com.hsrkill.game`、最低 SDK 23、目标 SDK 35、ARM64-v8a，并声明局域网所需网络权限。
