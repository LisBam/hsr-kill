# 插画资源目录

该目录用于集中保存卡牌插画与其他通用美术资源。武将插画不存放在本目录，统一放入 `game_data/characters/image`，由武将源码文件名自动定位。

```text
assets/art/
└── cards/          # 卡牌插画
```

建议卡牌插画使用接近 3:2 的横向主体构图。卡牌插画可使用 PNG、WebP、JPG 和可被 Godot 导入为 `Texture2D` 的 SVG，并在对应卡牌定义中填写 `art_path`。

添加资源后，在对应数据定义中填写项目资源路径：

```json
{"id":"sha", "art_path":"res://assets/art/cards/sha.webp"}
```

武将插画应使用竖向半身或全身构图，主体尽量位于中央。武将牌会将图片覆盖裁切到141.35×190.8像素槽位，左侧覆盖势力与竖排名称，右侧覆盖体力圆点，中下部可能覆盖最多5条141.35×15像素装备信息。具体同名规则见 `game_data/characters/image/README.md`。

卡牌 `art_path` 为空、缺失或指向无效资源，以及武将同名插画缺失时，界面都会继续显示统一占位图，不影响开局、规则结算、网络快照或存档结构。
