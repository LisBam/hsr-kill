## 一、GameSettings（`scripts/autoload/game_settings.gd`）

在 `user://game_settings.cfg`（**格式版本 1**）持久化全局设置。

### 持久化内容

- 全局卡牌名称模式
- 游戏流程间隔与 AI 响应延迟（均为 **0.10 ~ 1.00 秒**，步长 **0.05 秒**）
- 当前 UI 风格 ID
- 默认开启的自动身份标记
- 下一局人数（**按模式分槽保存**：身份 2~10 / 机缘大乱斗 2~10 / 胜者为王 2~10 / 斗地主 3 或 5 / 2v2 固定 4 / 1v1车轮战固定 2 / 过关斩将玩家数 2~4）
- 六项房主开局规则
- 座次补偿开关（**默认关闭**，只对胜者为王生效；同六项规则一样走内存优先 + 0.25 秒合并落盘）
- 过关斩将难度与机缘选择方式（`conquest_opportunity_choice_mode`：`vote` 投票 / `individual` 各自选择，默认投票）
- 联机玩家名称（最长 **20 字符**）与稳定武将形象 ID

### 取值约束（会主动拒绝非法值）

| 设置 | 合法取值 |
|---|---|
| 手气卡数量 | `0/1/2/3/4/5/10/-1`，其中 `-1` 表示无限张 |
| 换将卡数量 | `0/3/5/8/10/20` |
| 随机选将牌数 | `1 ~ 20` |
| 下一局人数 | 按模式规范化：2~10（身份/机缘大乱斗/胜者为王）、3 或 5（斗地主）、固定值（2v2 为 4、1v1车轮战为 2）、2~4（过关斩将玩家数） |
| 座次补偿开关 | 布尔值；非胜者为王模式读取时恒按关闭处理 |

速度设置直接按 **0.05 秒取整**，使 0.10~1.00 秒范围内每个档位都可写入。

### 写入策略（性能约定）

- 设置变化**先更新内存**，文件写入使用 **0.25 秒单次计时器合并**。
- **应用进入后台或节点退出时强制刷新。**
- 卡牌名称与 UI 风格的重绘信号**延迟到 GUI 输入结束后的空闲帧**。

### 明确不保存的内容

颜色字典、身份推断、网络对等体、地址、密码、房间成员、对局状态。

> **注意**：`GameSettings` 只有一份真实路径 `user://game_settings.cfg`，没有测试专用路径。
> 因此任何直接调用 `GameSettings` 单例的用例都会读写玩家正式设置文件。
> 这类用例必须在开头记录原值、结束时还原**并调用 `flush_pending_settings()` 强制落盘**——
> 写入有 0.25 秒合并延迟，而用例紧接着就 `quit()`，只还原不落盘会把临时值留在玩家配置里。
> 同时断言前必须先把目标字段归零：setter 对「值未变化」不重复发信号，也不重复排队写盘，
> 依赖初始值会让用例在「玩家手动开启过该开关」时假失败。

## 二、GameDatabase（`scripts/autoload/game_database.gd`）

静态内容仓库。扫描、校验、命名与索引规则见 [`../content/naming-and-directory.md`](../content/naming-and-directory.md)。

要点回顾：

- `_ready()` 调用 `reload_all()`，按**技能 → 卡牌 → 武将 → 牌堆 → 势力**顺序重载并校验。
- `validation_errors` 非空时 `MatchController.start_match()` **拒绝开局**。
- 查询返回深拷贝；持续装备与运行时技能必须用 `create_card_runtime()` / `create_skill()`。
- 说明文本按名称模式分组缓存，**每种模式最多 512 条**；`reload_all()` 会清空名称索引与文本缓存。
- **缓存只保存不可变字符串**，不保存技能节点、对局快照或运行时对象。

## 三、平台适配（`scripts/platform/`）

| 文件 | 职责 |
|---|---|
| `android_back_adapter.gd` | 系统返回键按当前界面执行取消、返回或打开局内菜单 |
| `android_display_stability.gd` | 显示稳定性策略 |
| `mobile_keyboard_guard.gd` | 软键盘显隐守卫 |

### Android 约定

- **横屏运行**：轻点卡牌/武将牌执行选择，拖动手牌调整同分区显示顺序，长按查看说明或详情。
- 渲染与帧率：**Vulkan Mobile** 渲染、**固定横屏**、**60 FPS 上限与 VSync**——用于避免一加 Ace 5 等高刷新率 Adreno 设备在启动、旋转或前后台切换时整屏闪烁。
- 触摸可直接操作卡牌名称/UI 风格下拉框、速度滑条、人数数字框、联机名称、房主 IP、端口、密码及创建/加入按钮。
- **软键盘边界**：进入联机大厅、连接成功、关闭文本设置或正式进入对局时主动隐藏软键盘；聊天输入法**只在玩家主动点击聊天框时**出现。
- **联机设置面板打开时不自动弹出输入法。**

### 分辨率

Android 使用 **1280×720** 横屏等比缩放；桌面布局测试以 **1152×648** 客户区为基准。

### 导出（`export_presets.cfg`）

包名 `com.hsrkill.game`、最低 SDK 23、目标 SDK 35、ARM64-v8a，并声明局域网所需网络权限。**仓库不保存签名密钥或密码。**

> 相关测试：`tests/android_adaptation_test.tscn`、`tests/game_settings_persistence_test.tscn`。
