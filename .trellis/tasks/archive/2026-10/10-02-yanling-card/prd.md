父任务：[`10-02-kafuka-new-mechanics`](../../../10-02-kafuka-new-mechanics/prd.md)

## 来源需求原文（不可变 · 逐字保留）

```
言灵yanling 梅花K 延时锦囊牌 专属锦囊牌

判定结果为梅花时，若场上有“主演”，本回合由“主演”操控。
```

配套 AI 原文（声明期望行为，不代表数值口径）：

```
（AI逻辑：如果主演是队友，则对敌人使用该牌，对距离其回合最近的敌人使用。如果主演是敌人，则不使用此牌。）
```

概念原文（已在前置子任务写入文档，本任务只复用）：

```
专属锦囊牌：正常情况不加入游戏中，只有被其他角色的技能或其他情况触发时才会按要求加入游戏。
```

```
本回合由xx操控：xx替你执行本回合，效果是操控者直接切换至被操控者的第一视角，被操控者不可做任何操作只能看着自己被操控。操控结束时操控者回到原来的角色。操控者是同时操控自己原来的角色和被操控角色的，可以参考设置中的“控制所有角色”。
```

## In Scope

1. 新增 `game_data/cards/yanling.gd`：静态元数据（`trick`/`delayed`/`exclusive`、梅花K、单目标、无距离限制、出牌次数 `0`、可被【无懈可击】抵消、结算后进入判定区）。
2. 覆盖 `resolve_delayed_judgment()`：未被抵消且判定为梅花且场上存在「主演」时，调用既有回合操控端口把本回合输入权交给「主演」。
3. 覆盖 `modify_ai_action_score()`：主演为队友时给基础正分、主演为敌人或不存在时否决、目标不是「距离主演回合最近的敌人」时否决。
4. 同步文档（内容制作指南字段总表、游戏机制与玩法内容、卡牌系统、AI 模块、README）。
5. 卡牌侧的静态与判定语义并入卡芙卡专项测试 `tests/kafuka_mechanics_test.gd`。

## Requirements

- **R1 静态元数据**：`id`/`original_name`/`custom_name` 均为 `yanling`/`言灵`；`type = "trick"`、`subtype = "delayed"`、`effect_id = "turn_control"`、`target_mode = "single_other"`、`1..1`、`distance_limit = "none"`、`play_limit = 0`、`response_pattern = "wuxie"`、`resolution_mode = "whole"`、`final_zone = "judgment"`、`exclusive = true`。
- **R2 固定牌面**：专属牌没有牌堆条目，因此由卡牌文件自己声明 `suit = "club"`、`rank = 13`（梅花K）；入堆端口在调用方未显式给出牌面时使用定义自带的这一对值。
- **R3 判定语义**：`resolve_delayed_judgment()` 三个条件缺一不可——未被抵消、判定花色为梅花、`get_starring_role_player_id() >= 0`；成立时 `begin_turn_input_delegation(当前回合角色, 主演)`。被抵消时直接弃置原延时牌。
- **R4 配套 AI**：`modify_ai_action_score()` 只做纯查询修正——主演为队友时基础分 `AI_ALLY_STARRING_VALUE = 6.0`；主演为敌人或以 `AI_REFUSE_SCORE = -100.0` 否决；目标不是「距离主演回合最近的敌人」时以 `AI_NON_NEAREST_TARGET_SCORE = -100.0` 否决。判定 AI 上下文提供 `AI_TARGET_SAFE_RESULT_VALUE = 4.0`。
- **R5 文本逐字**：`description` 必须与原文逐字一致（含全角引号 `“主演”` 与句末句号）。
- **R6 文档同步**：`docs/内容制作指南.md`（卡牌四张总表 + 玩家可见说明与源码函数表）、`docs/游戏机制与玩法内容.md`、`docs/卡牌系统.md`、`docs/AI模块.md`、`README.md`、`临时反馈文档.md`。

## 关键决策

| ID | 决策 | 采用值 | 理由 |
|---|---|---|---|
| K1 | 是否新增 `type` 取值表达专属 | **不新增**，只用 `exclusive` 布尔 | 核心多处按 `type == "trick"` 分支（延时锦囊检索、`CardRuleService`、基础 AI），新增 `type` 会从这些分支漏掉 |
| K2 | 牌面来源 | 由卡牌文件声明 | 专属牌没有牌堆条目，端口必须有可用的确定性回退；随机牌面会让「梅花」这一判定条件失去设计意义 |
| K3 | 判定改写方式 | 调用既有 `begin_turn_input_delegation()` | 卡牌「不认识」操控机制内部实现，与前置子任务保持解耦 |
| K4 | 主演为敌人时的 AI 行为 | 硬否决（`-100.0`） | 原文明确「如果主演是敌人，则不使用此牌」，不是权重偏好 |
| K5 | 「距离其回合最近的敌人」 | 按行动顺序求主演之后的第一个敌人 | 原文口径是时间距离而非座次距离；改用座次距离会在 2 人局与跳过离场时给出不同答案 |
