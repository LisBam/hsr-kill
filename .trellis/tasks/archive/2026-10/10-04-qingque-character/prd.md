# 青雀武将与三个技能（禁用手牌类牌·随机保留花色·视为使用）

## Goal

新增武将**青雀**（仙舟联盟 · 女 · 3 体力，稳定 ID `qingque`）与三个技能【独弈】`duyi`、【弃和】`qihe`、【自摸】`zimo`；配套为**全部卡牌**新增「是否为伤害牌」字段并完成全量伤害牌标注；含配套 AI、技能选牌界面与全部文档同步。

---

## 一、需求原文（不可变，逐字实现）

### 武将

| 项 | 值 |
|---|---|
| 显示名 | 青雀 |
| 稳定 ID | `qingque` |
| 势力 | 仙舟联盟（`xianzhou`） |
| 性别 | `female` |
| 体力上限 | `3` |

### 【独弈】`duyi`（锁定技）

> 锁定技，你不可使用或打出手牌中的基本牌和锦囊牌。弃牌阶段开始时，你随机保留每种花色的手牌各一张并弃置其余的牌，然后跳过该阶段。

（说明：本条原文由需求方在规划阶段二次修订，以「**手牌中的**基本牌和锦囊牌」为最终口径。）

### 【弃和】`qihe`（锁定技）

> 锁定技，当你成为其他角色使用伤害牌的目标时，若你手牌中有与此牌花色相同的牌，你随机弃置其中一张并令此牌对你无效。

### 【自摸】`zimo`（出牌阶段主动技）

> 出牌阶段，若你手牌中的牌花色数少于4，你可以摸一张牌，然后你视为使用一张【杀】或任意未以此法使用过的普通锦囊牌。若你手牌中的牌花色数不少于4，你可以弃置其中一种花色的所有手牌，并令此技能改为“出牌阶段限两次”直到回合结束。

### 需求方补充的口径与约束

1. **【独弈】与【自摸】的关系**：独弈只封锁**手牌中的**基本牌与锦囊牌；【自摸】制造的是**无实体虚拟牌**，不属于「手牌中的牌」，因此**不受独弈限制**，是青雀唯一的用牌手段。
2. **【自摸】可选锦囊范围**：`GameDatabase` 中**全部普通锦囊牌定义**；排除响应类锦囊【无懈可击】（`subtype = "counter"`）与全部延时锦囊（`delayed = true`）。
3. **【自摸】操作逻辑**：
   - 花色数 **少于 4**：发动 → 摸 1 张牌 → 弹出**选牌界面**（选【杀】或任一未以此法使用过的普通锦囊牌）→ 选完牌再选目标。选牌界面的表现方式**参考【灵感】**（以牌面形式展示候选牌）。
   - 花色数 **不少于 4**：发动 → 弹出**内联互斥选项**，每项对应手牌中现存的一种花色 → 选一种 → 弃置该花色的**全部**手牌，并令本技能改为「出牌阶段限两次」直到回合结束。
4. **【自摸】的「限两次」口径**：改为「出牌阶段限两次」后，**此前已经发动过的次数必须计入这两次之内**（即：不清零已发动次数，只把上限从 1 提升为 2）。
5. **【自摸】AI 口径**：回合内满足条件时**无脑发动**，不需要判断手牌是否真的有四种花色。
6. **【弃和】的「伤害牌」口径**：为**所有卡牌**新增一个「是否为伤害牌」字段，并把所有伤害牌标注为「是」；【弃和】按该字段判定，不写牌名白名单。
7. **原文不可变**：以上三段技能描述是玩家可见文本，必须逐字一致（含标点与语序）。

## 三、验收标准

### 【独弈】

- [ ] 青雀在自己出牌阶段**无法**使用手牌中的基本牌（【杀】【闪】【桃】【酒】等）与锦囊牌（普通、延时、响应类全部），UI 不点亮、AI 不枚举、权威提交被拒绝，且拒绝原因玩家可见。
- [ ] 青雀在响应窗口**无法**打出手牌中的基本牌与锦囊牌（含【闪】响应【杀】、【杀】响应【决斗】/【南蛮入侵】、【无懈可击】响应锦囊等）。
- [ ] 青雀**仍然可以**正常使用装备牌（装备主动动作与普通装备使用均不受影响）。
- [ ] 青雀通过技能产生的**虚拟牌**（无实体牌的视为使用）不受本限制。
- [ ] 青雀回合的**弃牌阶段开始时**：随机保留每种花色的手牌各 1 张（花色按手牌中现存的每种花色各取 1 张、随机取），其余手牌全部弃置；随后**跳过该弃牌阶段**（不出现正常弃牌流程）。
- [ ] 手牌为空、或只有一种/两种/三种花色时均正确：现存每种花色各保留 1 张，不凭空补牌，不报错。
- [ ] 随机选择使用本局权威随机源，同种子/回放/读档可复现（写入随机历史）。
- [ ] 「跳过的弃牌阶段」不产生任何手牌上限结算；已在弃牌阶段前触发的弃牌相关时机不丢。
- [ ] 技能为锁定技：满足条件强制执行，不创建可取消的发动询问。
- [ ] 青雀不是「不能使用装备」：`独弈` 只封锁两类牌，装备与技能入口保持可用。

### 【弃和】

- [ ] 仅在**其他角色**使用**伤害牌**并指定青雀为目标时触发；自己使用的伤害牌指定自己不触发。
- [ ] 判定条件为「青雀手牌中存在**与该伤害牌花色相同**的牌」；不存在同花色手牌时不触发、不弃牌。
- [ ] 触发时**随机弃置**这些同花色手牌中的 1 张（权威随机源，可复现），并令**该牌对青雀无效**。
- [ ] 「对该牌无效」只作用于青雀本人，不影响该牌对其他目标的正常结算。
- [ ] 伤害牌清单由卡牌「是否为伤害牌」字段决定，不写牌名白名单；标注清单交付前经需求方确认。
- [ ] 技能为锁定技：满足条件强制执行，不创建可取消的发动询问。
- [ ] 群体伤害牌（【南蛮入侵】【万箭齐发】）对每一名目标分别判定，青雀被指定时独立触发。
- [ ] 弃置触发的嵌套时机（弃牌后事件）不会让「该牌对青雀无效」丢失。

### 【自摸】

- [ ] 出牌阶段限一次（基础）；按钮在青雀出牌阶段且满足任一分支条件时点亮。
- [ ] **分支一（花色数 < 4）**：发动 → 摸 1 张牌 → 弹出参考【灵感】的牌面式选牌界面，候选为【杀】+ 全部普通锦囊牌定义中**未被本技能以此法使用过、且当前确实存在合法目标**的牌名 → 选牌（**此步不可取消**）→ 若该牌不需要玩家点目标则直接视为使用，否则进入选目标（**此步可取消**）→ 视为使用该牌。
- [ ] 选目标取消后**回到选牌名重新选择**：候选重新枚举并再次过滤「当前确实存在合法目标」；不重复摸牌、不重复消费次数、不返还已摸的牌。
- [ ] **分支二（花色数 >= 4）**：发动 → 弹出内联互斥选项（对手牌中**现存的每种花色**各一项）→ 选择一种 → 弃置该花色的**全部**手牌 → 本技能上限变为「出牌阶段限两次」直到回合结束。取消选项时不消耗额度、不移动牌。
- [ ] 次数消费口径：分支一在**摸牌时**消耗 1 次；分支二在**花色确认并完成弃置时**消耗 1 次；任何未完成的步骤都不消耗额度。
- [ ] 「限两次」生效后，**此前已发动的次数计入其中**：已发动 1 次时仅剩 1 次；回合结束后（或出牌阶段结束后）上限恢复为 1。
- [ ] 分支一「未以此法使用过的普通锦囊牌」的记录在**权威状态**中保存（可存档/读档/联机/回放复现），并在玩家可见处可查（技能说明或角标）。
- [ ] 分支一视为使用的【杀】/锦囊牌为无实体虚拟牌，不受【独弈】限制。
- [ ] 分支二弃置全部同花色手牌为**一次**弃置动作，不影响其他花色手牌。
- [ ] 取消分支二的花色选择时不消耗次数、不移动牌，且技能按钮恢复可点。
- [ ] 分支二先发动（额度 1/2）再发动分支一（额度 2/2）时，同一出牌阶段可完整使用两次；反之（先分支一后分支二）第二次发动只剩 0 次可用，符合「此前发动过也计入限两次」。
- [ ] AI：满足条件时主动发动；分支二的选项评估、分支一的牌名与目标评估均实现，不回退为永不发动或死循环。

### 通用

- [ ] `GameDatabase.validation_errors` 为空，可正常开局。
- [ ] 技能描述文本与上文原文**逐字一致**。
- [ ] 未新增技能 ID / 牌名白名单分支到 `MatchController`、`CardRuleService`、`BasicAIPolicy` 等核心层。
- [ ] 相关测试场景全部通过；`tests/smoke_test.gd` 的技能/武将总量断言已同步。
- [ ] 新增/修改的机制、接口、数值已写入 `docs/内容制作指南.md` 与 `docs/游戏机制与玩法内容.md`。

## 四、需求方已确认的口径（规划阶段问答结论）

1. **【自摸】「未以此法使用过的普通锦囊牌」按整局累计**：每个牌名整局只能被本技能以此法视为使用一次，不因回合或出牌阶段重置（与「直到回合结束」的显式时效形成对比）。因此该集合必须是**公开、可存档、可被 AI 读取**的权威状态。
2. **【自摸】分支一不可取消**：发动后「摸一张牌 → 选牌 → 选目标」全程 `allow_cancel = false`，必须完成一次真实的视为使用。为杜绝「无可结算组合」的死锁，选牌候选必须先过滤为**当前确实存在合法目标**的牌名；若一个可选牌名都没有，则技能按钮不点亮。
3. **「是否为伤害牌」只标注 9 张牌自身效果造成伤害的牌**：【杀】【火杀】【雷杀】【决斗】【南蛮入侵】【万箭齐发】【火攻】【水淹七军】【闪电】。定义＝「使用此牌时，其自身效果会造成伤害」；另有 6 张装备牌（白银狮子、古锭刀、寒冰剑、麒麟弓、藤甲、银月枪）的**装备效果**会造成伤害，但它们被使用时只是装备，标为「否」（不写该字段或写 `false`）。
