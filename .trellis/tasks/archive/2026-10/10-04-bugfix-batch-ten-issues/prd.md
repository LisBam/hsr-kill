# 修复泛音目标选择·借刀杀人生息时机·阿哈时刻触发·判定顺序等十项问题

> 本任务是一次**批量缺陷修复**：十个问题各自独立、可独立验收，但共享一次交付与一次提交。
> 规划深度按「复杂任务」执行（`prd.md` + `design.md` + `implement.md`），因为改动横跨 `content` / `core` / `ui` / `adapters` 四层。

## Goal

修复玩家实测反馈的十项缺陷，覆盖四层：

| 层 | 涉及问题 |
|---|---|
| `content`（`game_data/`） | ①【泛音】黑色效果 AI 目标、②【借刀杀人】所用【杀】的时机、⑤【自摸】借刀目标枚举 |
| `core`（`scripts/core/`） | ④ 判定区判牌顺序、⑥ 不可用牌仍可选目标 |
| `ui`（`scripts/ui/`） | ⑧【朱雀羽扇】选中态、⑩【自摸】取消按钮 |
| `adapters`（`scripts/ai/`） | ⑦ 青雀 AI 使用【自摸】虚拟牌、⑨【刃】在斗地主用【杀】指定自己 |
| 模式 | ③ 过关斩将阿哈时刻不触发 |

用户价值：消除四条会直接改变胜负与操作手感的规则缺陷（AI 打队友、时机漏派发、判定顺序反了、不可用牌仍可点目标），并让青雀与刃两名武将的 AI 恢复正常强度。

## 来源需求原文（不可变 · 逐字保留）

> 依据 [`项目专属AGENTS.md`](../../../项目专属AGENTS.md) 铁律：以下描述原文的字段、数值、文字表述、标点符号与语句顺序**一律不得改动**。实现必须围绕原文展开。

```
1. “泛音”是弃置黑色牌时触发的效果是对敌人发动的，为什么ai一直对队友发动，请修复。

2. 因“借刀杀人”使用的【杀】也是走“使用”逻辑的，因此也要触发“使用”时机的技能，例如“生息”

3. 过关斩将模式中有bug，他竟然不会触发阿哈时刻，不知道是不是敌方切换武将上场，导致原先没有阿哈时刻，即使出现欢愉技也不触发阿哈时刻的问题。

4. 判定阶段时，判定区内的牌判定顺序是“后来居上”，即先进入判定区的牌晚判定，晚进入判定区的牌先判定。

5. 修复“自摸”【借刀杀人】指定角色的bug，有时候有些装备区有武器牌的角色不能成为借刀目标，并且装备区没武器牌的角色不能成为被杀的目标

6. 铁索连环不能使用时是不能指定目标的，目前有bug，即使不可使用，也是能够选择目标（虽然确实不能进一步确认使用）。如“独弈”影响的铁索连环。

7. 修复青雀ai不会正常使用“自摸”视为使用牌的问题。“自摸”的牌青雀需要像手牌一样判断每张牌的收益和目标才对。

8. 修复bug：“自摸”视为使用普通【杀】时，朱雀羽扇会自动选择，然后又被覆盖，导致询问是否发动朱雀羽扇时不能直接点击确定，而是要再点一次装备区里的朱雀羽扇取消选中，然后再点一次装备区的朱雀羽扇确认选择，这样才能正常点击确认或取消。

9. 修复刃在斗地主时不会通过使用【杀】指定自己达到杀敌人的目标的问题。

10. 发动“自摸”时选牌时不能点击取消，请直接暗置取消按钮，而不是摆着让人可以点击但点击了却不生效
```

## 验收标准

每一项都必须**有可执行的验证证据**，不接受「应该通过」。

- [ ] ① 【泛音】黑色效果的 AI 目标评分中，敌对角色严格高于队友角色；仅当场上无敌对候选时才退化为队友。人类候选集与提示文本不变。
- [ ] ② 【借刀杀人】要求持刀者使用的【杀】派发「使用」系时机（`useCard`），订阅该时机的技能（如【生息】）正常触发；本牌原有的「持刀者 → 被杀者」顺序、武器转移与拒绝分支不变。
- [ ] ③ 过关斩将中敌方整层换将后，新敌方武将与新获得的【欢愉技】能正常触发阿哈时刻；不因换将而丢失本轮阿哈时刻额度，也不重复触发。
- [ ] ④ 判定阶段按「后来居上」结算：最后置入判定区的延时锦囊最先判定。判定区数组顺序与界面显示顺序保持**置入顺序**不变。
- [ ] ⑤ 【自摸】视为使用【借刀杀人】时，合法组合覆盖「装备武器者作为第 1 目标」的全部真实可能；装备区无武器的角色可以作为第 2 目标（被杀者）。不再出现「有武器者不能成为借刀目标」与「无武器者不能成为被杀目标」。
- [ ] ⑥ 被【独弈】禁止使用的【铁索连环】不再能进入目标选择态（无候选、不可点目标）；但牌面仍可查看，且「重铸」路径照常可用。
- [ ] ⑦ 青雀 AI 对【自摸】选出的虚拟牌按项目统一的牌效与目标评分判断，像判断手牌一样比较每张候选的收益与目标；不再出现「不发动」或「选了明显亏的牌」。
- [ ] ⑧ 【自摸】视为使用普通【杀】时，询问是否发动【朱雀羽扇】可以直接点击「确定」确认（装备区不出现需要二次点击的残留选中态）。
- [ ] ⑨ 【刃】在斗地主模式中，AI 能通过「使用【杀】指定自己」达成其技能目标。
- [ ] ⑩ 发动【自摸】的选牌窗口中「取消」按钮被**暗置**（不可见、不可点），而不是可见但点击无效。
- [ ] 全部十项改动后 `GameDatabase.validation_errors` 为空，可正常开局。
- [ ] 至少运行与本改动直接相关的测试场景并给出实际输出：`gameplay_regression_test`、`qingque_mechanics_test`、`ai_policy_test`、`conquest_mode_test`、`virtual_hand_choice_test`、`ui_layout_test`。
- [ ] `docs/游戏机制与玩法内容.md`、`docs/内容制作指南.md`、`docs/卡牌系统.md`、`docs/AI模块.md`、`docs/界面与交互.md`、`README.md` 按改动范围同步。
- [ ] 已产出「学习反馈摘要」与「Git 提交描述」，并追加写入 `临时反馈文档.md`。
