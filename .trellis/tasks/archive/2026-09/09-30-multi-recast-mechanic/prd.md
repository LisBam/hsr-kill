# 多张重铸机制

## Goal

在核心层新增「一次重铸多张牌」的权威端口：把多张手牌**一次性**置入弃牌堆，然后摸等量的牌；语义与现有单张重铸完全一致（不构成使用、打出、弃置），供【连戏】等后续内容复用。

来源：父任务 `09-30-huanyu-ahha-system`。需求原文见父任务 `prd.md` 的「新机制：重铸多张牌」条目。

## Background

- 现有单张重铸端点为 `match_controller.gd:12715` 的 `recast_hand_card(player_id, card_uid) -> bool`，其语义注释在 `:12729`-`:12737`：移入弃牌堆时传 `_move_to_discard(card, -2, false)`，因此不派发 `cardsDiscardedBatchAfter`、不触发「当你弃置牌时」类技能、不写「弃置了」日志、不进入处理区；随后固定摸 1 张牌。
- 命中嵌套结算屏障时（`:12735`），单张版本用 `_defer_rule_continuation("recast_draw", {"player_id":...})` 延后补摸。
- 依赖现有文本「重铸了」的既有测试：`card_action_semantics_test.gd:319`（重铸不构成使用/打出/弃置、日志只出现「重铸了」）、`gameplay_regression_test.gd:827`（木牛流马「粮」不可作为重铸来源）。
- 需求明确给出的交互语义：**「而不是一张一行重铸」**——因此一次动作必须只产生一组移动与一次等量补摸，而不是循环调用单张端口。

## Requirements

### R1 新增权威端口
- 在 `match_controller.gd` 的 `recast_hand_card` 之后新增：
  `func recast_hand_cards(player_id: int, card_uids: Array[int]) -> int`
- 返回值 = **实际重铸张数**；返回 `0` 表示一张都没有被重铸，调用方不得据此产生任何后续效果（如【连戏】不得因 0 张而累计重铸次数）。

### R2 语义等价性（与单张重铸逐条一致）
- 不构成「使用」、不构成「打出」、**不构成「弃置」**。
- 不派发 `cardsDiscardedBatchAfter`，不触发弃置类技能。
- 牌只进入弃牌堆，不进入处理区。
- 不写「弃置了」日志；只写重铸日志。

### R3 日志
- 多张路径写一条 `"%s重铸了%d张牌。"`。
- 单张路径**保持**原有 `"%s重铸了%s。"` 文本与 `bool` 返回类型**完全不变**（既有测试依赖）。

### R4 校验与边界
- 角色不存在、已死亡或已离场 → 返回 `0`，不产生任何移动。
- 每张 UID 必须仍位于**普通手牌区**（经 `find_hand_card` 复核）；装备区、木牛流马「粮」、判定区牌一律不参与。
- 传入重复 UID 时只重铸一次（去重后计数）。
- 传入空数组或全部无效 UID → 返回 `0`，不摸牌、不写日志。

### R5 续接与屏障
- 全部牌移入弃牌堆后，若命中 `_has_nested_settlement_barrier()`，延后补摸（沿用 `_defer_rule_continuation` 机制，上下文需携带张数），屏障清空后补摸等量牌。
- 补摸张数 = 实际重铸张数（不是传入的 UID 数量）。

### R6 不重复实现
- 单张与多张必须共用同一条私有移动/日志/续接路径，禁止复制两份移牌逻辑（项目「移牌唯一边界」约束）。

## Acceptance Criteria

- [ ] 一次调用把 N 张普通手牌全部移入弃牌堆，并摸 N 张牌（N = 实际有效 UID 数）。
- [ ] 重铸 3 张后：弃牌堆增加 3 张、摸牌堆减少 3 张、手牌净变化 0（三张离手 + 三张入手）。
- [ ] **不产生弃置语义**：不派发弃置批次、不触发「当你弃置牌时」类技能、日志中不出现「弃置了」。
- [ ] 公开日志只出现一条重铸记录，且包含张数。
- [ ] 传入重复 UID（如 `[A, A, B]`）返回 `2`，且 A 只被重铸一次。
- [ ] 传入装备区牌 / 木牛流马「粮」/ 判定区牌 UID 时，这些牌不被移动，返回值不计入它们。
- [ ] 角色已死亡或已离场时返回 `0`，弃牌堆与摸牌堆均无变化。
- [ ] 空数组返回 `0`，不写日志、不摸牌。
- [ ] 单张重铸 `recast_hand_card` 的返回类型、日志文本、语义与改动前完全一致：`card_action_semantics_test` 与 `gameplay_regression_test` 保持 PASS。
- [ ] 新增 `res://tests/multi_recast_test.tscn` 场景并 PASS。
- [ ] `card_action_semantics_test` / `gameplay_regression_test` / `gameplay` 相关回归全部 PASS。

## Out of Scope

- 【连戏】技能本身（由子任务 `09-30-huohua-character` 交付）。
- 为**实体牌**新增「多张重铸」的玩家入口（当前只有【铁索连环】支持主动重铸，且是单张；本次不改变卡牌自身的重铸入口）。
- 改变现有单张重铸的任何行为（包括日志文本）。

## Key Decisions

| 决策 | 结论 | 来源 |
|---|---|---|
| 端口签名 | `recast_hand_cards(player_id, card_uids) -> int`，返回实际张数 | 父任务 design |
| 与单张的关系 | 共用同一条私有路径，单张行为与日志零变更 | 父任务 design |
| 0 张的含义 | 返回 `0`，调用方不得产生后续效果 | 本任务（防【连戏】空转累计次数） |
