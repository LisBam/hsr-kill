# 武将火花与技能好戏连戏

## Goal

交付首个欢愉派系内容：新势力「欢愉」、武将**火花**（女 · 欢愉 · 体力 3）与其两个技能——欢愉技【好戏】（参演编号 144）与出牌阶段主动技【连戏】，两者都带配套 AI。

来源：父任务 `09-30-huanyu-ahha-system`。依赖子任务 `09-30-ahha-joy-mechanic`（欢愉技机制）与 `09-30-multi-recast-mechanic`（多张重铸端口）的接口先就位。

## 需求原文（逐字保留，不得改写）

```text
火花huohua 女 欢愉派系 体力值3
好戏haoxi
欢愉技，参演编号144，你可弃置0-2名其他角色各一张随机手牌，然后从牌堆中获得X张基本牌。（X为2-本次选择的目标数）
（AI逻辑参考：手牌中基本牌为0时优先少选一名目标来换基本牌；敌人手牌数越少，指定其为目标的收益越高；敌人手牌数多则可以直接不选择这名敌人而换取基本牌。）
（代码操作逻辑：触发时选择0-2名角色再点确定，可以不选择角色直接点确定，然后获得基本牌。）

连戏lianxi
出牌阶段限一次，你可以重铸你手牌中的所有基本牌，你可以重复此流程（至多重铸七次），最后对一名其他角色造成Y点伤害。（Y为你本次重铸的次数/2，向下取整）
（代码操作逻辑：发动此技能后直接重铸手牌中所有基本牌，然后询问“当前已重铸y次，是否继续重铸？，如果选择是，则继续重复重铸和询问，直到选择否或者手牌中没有基本牌，则让玩家选择目标，然后造成伤害。）
```

## Background

- 武将文件格式见 `game_data/characters/xiluwa.gd`（`super({...}, [SKILL_A, SKILL_B])`，技能以 `preload` 直接引用脚本）。
- 势力记录格式见 `game_data/factions.json`：`{"id","display_name","short_name","color"}`；`id` 用完整小写拼音，`huanyu` 与现有 `xingjianhuanyv`（星间寰宇）不冲突。
- 技能必须自带配套 AI（见 `.trellis/spec/content/content-ai.md`），且 `docs/内容制作指南.md` 是内容制作的唯一权威手册。

## Requirements

### R1 欢愉势力
- `game_data/factions.json` 追加：`{"id":"huanyu","display_name":"欢愉","short_name":"欢","color":"e0673c"}`。
- 追加后全项目势力记录仍通过 `GameDatabase` 校验，且选将/全武将入口按势力顺序正常展示（不破坏现有排序）。

### R2 武将火花
- 文件 `game_data/characters/huohua.gd`（`extends CharacterDefinition`）。
- 元数据：`id="huohua"`、`display_name="火花"`、`gender="female"`、`faction="huanyu"`、`max_hp=3`。
- 技能引用：`res://game_data/skills/haoxi.gd`、`res://game_data/skills/lianxi.gd`（顺序即技能栏顺序：好戏在前，连戏在后）。
- `description`：一句话概括武将玩法，风格与现有武将一致。

### R3 【好戏】`haoxi`
- 静态：`id="haoxi"`、`name="好戏"`、`joy_skill=true`、`performance_number=144`。
- 玩家可见 `description` **逐字**：
  `欢愉技，参演编号144，你可弃置0-2名其他角色各一张随机手牌，然后从牌堆中获得X张基本牌。（X为2-本次选择的目标数）`
- 触发方式：**仅**由阿哈时刻驱动（`perform_joy_skill`），不生成主动按钮。
- 交互（按需求「代码操作逻辑」）：先选 0-2 名其他角色 → 点确定（可不选任何角色直接确定）→ 获得 X 张基本牌（X = 2 − 本次选择的目标数）。
- 效果：
  1. 对每个被选中的目标**随机弃置其一张手牌**（随机源走权威随机流 `pick_random_candidate_index`）。
  2. 从牌堆中**随机抽取** X 张基本牌加入技能持有者手牌（复用 `gain_draw_pile_card_by_uid`；牌堆基本牌不足 X 张时按实际可得数量结算，不报错）。
- 配套 AI（需求参考 + 通用补全）：手牌中基本牌为 0 时优先少选一名目标来换基本牌；目标手牌数越少，指定其为目标的收益越高；目标手牌数多则可以不选它而换取基本牌。

### R4 【连戏】`lianxi`
- 静态：`id="lianxi"`、`name="连戏"`、`ui_enabled=true`、`enable` 含 `phaseUse`（出牌阶段主动发动）。
- 玩家可见 `description` **逐字**：
  `出牌阶段限一次，你可以重铸你手牌中的所有基本牌，你可以重复此流程（至多重铸七次），最后对一名其他角色造成Y点伤害。（Y为你本次重铸的次数/2，向下取整）`
- 流程（按需求「代码操作逻辑」）：
  1. 发动后**直接**重铸手牌中所有基本牌（一次动作，走 `recast_hand_cards`；若发动时手牌没有基本牌则不进入本技能）。
  2. 询问「当前已重铸 y 次，是否继续重铸？」——**仅当**本次重铸后手牌中仍有基本牌**且**未达 7 次上限时询问。
  3. 选「是」→ 重复「重铸全部基本牌 → 询问」；选「否」或手牌已无基本牌或已达 7 次 → 进入目标选择。
  4. 让玩家选择一名其他角色 → 造成 Y = ⌊本次重铸次数 / 2⌋ 点伤害。
- 出牌阶段限一次：额度按项目既有 `PLAY_PHASE_USAGE_FIELDS` 机制复原。
- 配套 AI（需求未给参考，按项目规范补全通用逻辑）：至少能判定「是否发动 / 是否继续重铸 / 选择哪个目标」。

### R5 一致性与补全说明
- 两个技能的玩家可见文本必须与需求原文逐字一致（`name` 与 `description`）。
- 需求未明确、但落地必需的配套边界（如候选目标范围、无基本牌时能否发动），按项目通用设计逻辑补全，并**在交付说明中单独告知**（见 `项目专属AGENTS.md` 2.1）。

## Acceptance Criteria

- [ ] 选将界面与「所有武将」入口均能看到势力「欢愉」，颜色为橙红色 `#e0673c`，短名为「欢」。
- [ ] 火花初始体力为 3，势力显示为「欢愉」，性别为女。
- [ ] 技能栏显示【好戏】与【连戏】，且【好戏】**没有**可点击的主动按钮。
- [ ] 【好戏】的说明面板文本与需求原文逐字一致（含全角括号与半角连字符）。
- [ ] 【连戏】的说明面板文本与需求原文逐字一致。
- [ ] 阿哈时刻触发时，火花持有【好戏】则自动进入其目标选择；选 0 名目标 → 获得 2 张基本牌；选 1 名 → 获得 1 张；选 2 名 → 获得 0 张。
- [ ] 被【好戏】选中的每个目标各被弃置一张**手牌**（随机，非其自行选择）；无手牌的角色不作为候选。
- [ ] 【好戏】获得的基本牌确实来自**牌堆**且 `type == "basic"`；牌堆可用的基本牌不足时按实际数量获得且不报错。
- [ ] 【连戏】发动一次后：手牌中的基本牌被一次性重铸（走多张重铸端口，非逐张），补摸等量牌。
- [ ] 【连戏】重铸后若仍有基本牌且未满 7 次，弹出「当前已重铸 y 次，是否继续重铸？」询问；选「是」继续，选「否」进入目标选择。
- [ ] 【连戏】最多重铸 7 次；第 7 次后不再询问，直接进入目标选择。
- [ ] 【连戏】伤害为 ⌊重铸次数 / 2⌋：重铸 1 次 → 0 点；2-3 次 → 1 点；4-5 次 → 2 点；6-7 次 → 3 点。
- [ ] 【连戏】每出牌阶段只能发动一次；额度在本阶段内不因取消目标选择而返还之外的重复发动机会。
- [ ] 【好戏】的 AI 在「手牌中基本牌为 0」时会为换取基本牌而少选目标；对低手牌敌人倾向指定，对高牌敌人倾向放弃。
- [ ] 【连戏】的 AI 能对合法动作给出合理评分，不产生「发动→取消」的空转循环。
- [ ] `GameDatabase.validation_errors` 为空，`smoke_test` PASS 并能正常开局。
- [ ] `ai_policy_test` PASS（新增技能的 AI 钩子不破坏基础 AI）。

## Out of Scope

- 其他欢愉派系武将（本任务只交付火花；机制本身在子任务①中已可扩展）。
- 武将插画资源（`game_data/characters/image/huohua.png` 缺失时按既有占位图逻辑显示，不产生校验错误）。
- 技能专属音效与语音。
- HUD/技能栏的视觉改版。

## Key Decisions

| 决策 | 结论 | 来源 |
|---|---|---|
| 【好戏】基本牌获取方式 | 从牌堆中**随机抽取** X 张基本牌 | 用户确认 |
| 势力展示数据 | `display_name="欢愉"`、`short_name="欢"`、`color="e0673c"` | 用户确认 |
| X 的计算口径 | 按**本次选择的目标数**（原文：「X 为 2-本次选择的目标数」） | 需求原文 |
| 【好戏】候选目标 | 限定为**有手牌**的其他存活角色（要「各一张随机手牌」，无手牌无法弃置） | 配套补全 |
| 【连戏】无基本牌时 | 手牌无基本牌时不开放技能入口（发动也不产生任何效果） | 配套补全 |
| 欢愉技的 `lock` | 保持 `false`：强制来自阿哈时刻驱动，不占用锁定技语义 | 配套补全 |
