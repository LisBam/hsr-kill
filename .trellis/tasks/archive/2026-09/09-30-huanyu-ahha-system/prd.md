# 欢愉派系与阿哈时刻体系

## Goal

在《崩铁杀》中新增一条完整的内容与规则支线：**欢愉派系**（新势力）、**阿哈时刻**（新触发时机）、**欢愉技 / 参演编号**（新技能分类与排序执行机制）、**多张重铸**（新卡牌操作机制），并交付首名欢愉派系武将 **火花**（技能【好戏】【连戏】）。

玩家价值：为对局引入第二个「回合开始前全体触发」的随机事件（阿哈时刻），让欢愉派系武将的技能以「按编号依次登台演出」的方式自动结算，形成与机缘选择并列、但机制独立的新玩法层。

## Background

- 项目为 Godot 4.6 + GDScript 的身份制同人桌游，权威规则集中在 `scripts/core/match_controller.gd`，静态内容自包含于 `game_data/{cards,skills,characters}`。
- 机缘选择已有完整的「回合开始前触发 + 每轮一次 + 概率 1/在场人数」实现，是阿哈时刻的**参照机制**（触发时机与概率算法复用其口径，机制本身独立）。
- 项目当前不存在任何欢愉 / 阿哈 / 参演编号相关代码（已检索确认），属于全新机制。

## Requirements

### R1 欢愉派系（势力）
- 在 `game_data/factions.json` 新增欢愉派系，显示名「欢愉」、短名与颜色按项目现有势力表结构给出，颜色为**橙红色**。
- 新势力可被武将引用、可被选将界面与全武将入口正常读取与排序。

### R2 阿哈时刻（触发时机）
- 触发时机与机缘选择一致：**每名角色的回合开始前**（回合事实尚未建立时）参与一次判定。
- 触发概率算法与机缘选择一致：本轮开始时按**在场（存活且未离场）角色数倒数**计算并锁定到轮末。
- 每轮**至多触发一次**阿哈时刻。
- 阿哈时刻与机缘选择**各自独立**：同一轮内机缘已触发，不影响阿哈时刻按自身概率判定；反之亦然。
- 触发时机的实现不得破坏现有回合开始流程与机缘流程的既有顺序。

### R3 欢愉技与参演编号（技能分类）
- 新增技能分类「欢愉技」，技能可通过静态参数声明自己属于欢愉技并携带**参演编号**。
- 阿哈时刻触发时，场上所有**可执行的欢愉技**按**参演编号由小到大**依次执行。
- 参演编号相同时，按**以当前回合位置（即将开始回合的角色）起算的座次顺序**执行。
- 欢愉技由阿哈时刻**强制依次执行**，不生成独立的主动发动按钮；执行期间玩家/AI 的选择（如【好戏】选目标）仍按统一选择协议进行。
- 已死亡或已离场的角色不参与阿哈时刻的欢愉技执行。

### R4 多张重铸机制
- 新增权威端口：一次将**多张牌**置入弃牌堆，然后**摸等量的牌**。
- 语义与现有单张重铸一致：不构成「使用」「打出」，也**不构成「弃置」**（不派发弃置批次、不触发弃置类技能），仅写重铸日志。
- 该端口需被【连戏】与后续内容复用，不得在技能内自行拼装移牌流程。

### R5 武将火花（huohua）
- `game_data/characters/huohua.gd`：女、欢愉派系、体力值 3。
- 【好戏】`haoxi`：欢愉技，参演编号 144，弃置 0-2 名其他角色各一张随机手牌，然后从牌堆中随机获得 X 张基本牌（X = 2 - 本次选择的目标数）。
  - 交互：触发时先选 0-2 名角色再点确定；可不选任何角色直接确定，然后获得基本牌。
  - 配套 AI：按需求给出的参考逻辑实现评分与目标选择。
- 【连戏】`lianxi`：出牌阶段限一次，重铸手牌中所有基本牌，可重复该流程（至多 7 次），最后对一名其他角色造成 Y 点伤害（Y = 本次重铸次数 / 2 向下取整）。
  - 交互：发动后直接重铸手牌中所有基本牌，然后询问「当前已重铸 y 次，是否继续重铸？」；选「是」继续，选「否」或手牌已无基本牌则让玩家选择目标并造成伤害。
  - 配套 AI：至少能判定是否发动、是否继续重铸、选择哪个目标。
- 技能描述文本必须与需求原文**逐字一致**。

## Acceptance Criteria

- [ ] 选将/全武将入口可见「欢愉」势力，颜色为橙红色，短名与现有势力表风格一致。
- [ ] 一场对局中，阿哈时刻每轮至多触发一次，且与机缘是否触发互不影响；固定种子下触发结果可复现。
- [ ] 阿哈时刻触发时，场上所有可执行欢愉技按「参演编号升序、同编号按当前回合位置起算的座次」依次执行，且在执行前完成公开提示。
- [ ] 参演编号相同的两个欢愉技，执行顺序随触发角色的座次变化而改变（可被测试断言）。
- [ ] 欢愉技角色死亡或离场后，其欢愉技不再参与阿哈时刻。
- [ ] 【好戏】可选择 0-2 名其他角色；选 0 名时获得 2 张基本牌，选 1 名获得 1 张，选 2 名获得 0 张；被选目标各被随机弃置一张手牌。
- [ ] 【好戏】获得的基本牌确实来自牌堆且为基本牌；牌堆基本牌不足时按实际可得数量结算且不报错。
- [ ] 【连戏】一次发动内可重铸 1-7 次，每次重铸手牌中全部基本牌并补摸等量牌；选择「否」或无可重铸基本牌后进入目标选择并造成 ⌊重铸次数/2⌋ 点伤害。
- [ ] 多张重铸不产生「弃置」语义：不触发弃置类技能、不派发弃置批次、公开日志只出现「重铸」。
- [ ] 新增内容不破坏现有测试：`smoke_test`、`gameplay_regression_test`、`phase_progression_test`、`card_action_semantics_test`、`event_runtime_test` 全部通过。
- [ ] `docs/内容制作指南.md` 与 `docs/游戏机制与玩法内容.md` 已同步新机制、新势力与全部具体数值（概率、编号、体力、伤害公式、重铸上限）。

## Out of Scope

- 除火花外的其他欢愉派系武将（仅建立可扩展机制，不批量产出内容）。
- 阿哈时刻的独立美术/音效资源制作（仅接入现有提示与日志通道）。
- 机缘选择机制本身的任何行为改动（除必要复用外不改动其触发与结算逻辑）。
- 联机与存档的额外兼容层（沿用现有随机历史与快照通道）。

## Key Decisions

| 决策 | 结论 | 来源 |
|---|---|---|
| 参演编号排序方向 | 编号**小 → 大** | 用户确认 |
| 阿哈时刻与机缘的次数关系 | **各自独立**，同一轮可都触发 | 用户确认 |
| 【好戏】基本牌获取方式 | **从牌堆中随机抽取** X 张基本牌 | 用户确认 |
| 任务拆分 | 父任务 + 3 个子任务 | 用户确认 |
